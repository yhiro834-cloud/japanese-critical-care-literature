# Infection / Sepsis — Clinical Questions

1. **培養のため抗菌薬を待つか。** 適切な検体を迅速に採るが、septic shock等でmeaningful delayを作らない。
2. **positive cultureは感染確定か。** specimen quality、colonization/contamination、複数set、臨床sourceで判断する。
3. **culture negativeならde-escalationできないか。** SSC 2026は病原体未同定でも臨床評価に基づくde-escalationを提案する。
4. **PCT単独で抗菌薬を止めるか。** いいえ。adequate source control後にclinical evaluationと併用する。
5. **CRRT中の標準doseを固定できるか。** residual function、effluent/downtime、体格、MIC/TDM等で個別化する。
6. **source control failureを示す所見は。** persistent shock/fever/bacteremia、drain不良、進行画像、継続汚染等。
