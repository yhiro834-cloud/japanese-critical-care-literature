# Hematology — Clinical Questions

1. **platelet低下 + PT延長ならDIC確定？** いいえ。基礎疾患、trend、fibrin markerとmimicを統合する。
2. **HIT testは全低plateletに提出？** pretest probabilityを先に評価する。
3. **TTPはADAMTS13結果まで待つ？** 高疑いならplasma exchangeを遅らせない。
4. **Hb閾値だけでRBC輸血？** symptoms、出血、ischemia、oxygen deliveryを統合する。
5. **INR正常化のためplasma？** bleeding/procedureとfactor deficitの臨床適応で判断する。
6. **輸血中発熱は観察継続？** 輸血停止、患者評価、blood bank連絡を行う。
7. **PT/aPTT正常ならDOAC effectなし？** agentにより除外できない。
8. **VTE prophylaxisは入院時一度決める？** VTE/bleeding riskを毎日・procedure前後に再評価する。
