# GI / Liver / Pancreas — Clinical Questions

1. **初期Hb正常なら大量GI出血なし？** いいえ。acute lossは単発Hbで除外しない。
2. **hematocheziaは必ずlower source？** instability時はupper sourceも考える。
3. **INR高値ALFはroutine FFP？** 出血/procedure等の適応とglobal hemostasisで判断する。
4. **ammonia高値だけでHE確定？** mimicと臨床神経所見を統合する。
5. **ALFは予後score後に転送相談？** 早期にtransplant centerへ相談する。
6. **膵炎は大量輸液ほどよい？** response/toleranceでmoderately調整する。
7. **壊死性膵炎は予防的抗菌薬？** sterile necrosisへのroutine prophylaxisは避ける。
8. **腹部が軟らかければIAHなし？** riskがあればstandardized IAPを測る。
