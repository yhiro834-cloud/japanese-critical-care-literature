# Pharmacology / Nutrition — Clinical Questions

1. **AKIならloading doseも必ず減らす？** Vdとclearanceを分けて考える。
2. **CRRTなら標準dose一つ？** modality/effluent/downtime/residual functionで変わる。
3. **TDM値だけでdose変更？** sampling timing、assay、clinical endpointを統合する。
4. **pump libraryがあれば誤投与なし？** concentration/unit/line/dead spaceを人が確認する。
5. **albumin低値＝栄養不足？** inflammation等の影響が大きく、nutrition assessment単独指標にしない。
6. **EN intoleranceはresidualだけ？** 症状、perfusion、腹部、trajectoryを統合する。
7. **goal caloriesへ初日から到達？** illness phaseとrefeeding riskで段階化する。
8. **refeedingはPNだけ？** oral/EN/IV dextroseでも起こる。
