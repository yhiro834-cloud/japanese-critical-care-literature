# Renal — Clinical Questions

1. **SCrが正常ならAKIはないか。** 早期や希釈下では否定できず、尿量とtrajectoryを併用する。
2. **oliguriaにはfluidか。** perfusion、responsiveness、congestion、obstructionを評価して決める。
3. **hyperkalemiaでcalciumを投与すればKは下がるか。** 下がらない。膜安定化でありshift/removalが別に必要。
4. **CRRT開始をcreatinine値で決めるか。** emergency complication、trajectory、demand–capacity、goalsで判断する。
5. **prescribed CRRT doseとdelivered doseが違う理由は。** downtime、access、clot、dilution等。
6. **KDIGO 2026 draftを現行推奨としてよいか。** 最終版ではないため不可。更新statusを追跡する。
