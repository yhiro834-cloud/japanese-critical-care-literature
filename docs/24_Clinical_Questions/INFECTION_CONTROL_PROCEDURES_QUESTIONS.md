# Infection Control / Procedures — Clinical Questions

1. **glovesでhand hygiene不要？** いいえ。着脱前後と適切な時点で行う。
2. **病原体確定までisolation不要？** syndrome/exposureからempiric追加する。
3. **urine混濁ならCAUTI？** symptoms、specimen、alternative sourceを評価する。
4. **central lineは定期交換でCLABSI予防？** daily necessityとmaintenanceが中心。
5. **emergencyならtimeout不要？** 可能な範囲で短いcritical checkを行う。
6. **ultrasoundがあれば安全？** needle-tip visualizationとoperator competencyが必要。
7. **device placement成功＝使用可能？** position/function/complication確認が別に必要。
8. **needlestickはshift後報告？** time-sensitive PEPのため即時洗浄・報告する。
