# PADIS / Rehabilitation / PICS — Clinical Questions

1. **agitationは鎮静不足？** pain、hypoxia、withdrawal、retention、delirium等を先に評価する。
2. **RASS低値なら快適？** oversedationやparalysisでは痛みを除外しない。
3. **CAM-ICU陽性ならantipsychotic？** 原因修正とbundleが中心。
4. **NMBA中はsedation不要？** analgesia/sedationを独立して保証する。
5. **vasopressor中はmobility禁止？** trajectoryと安全screenで個別化する。
6. **ICU-AWは全身廃用だけ？** focal/rapid changeは別疾患を検索する。
7. **退院時歩ければPICSなし？** cognition/mental health/familyもscreenする。
8. **家族は情報受取者だけ？** goals、routine、care、recoveryのpartnerである。
