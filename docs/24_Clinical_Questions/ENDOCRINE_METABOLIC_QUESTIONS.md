# Endocrine / Metabolic — Clinical Questions

1. **glucose <200ならDKAなし？** SGLT2、妊娠、絶食等でeuglycemic DKAがあり、ketosis/acidosisを確認する。
2. **glucose正常化でDKA治癒？** いいえ。ketosis/acidosis resolutionが必要。
3. **DKAのinsulinはKに関係なく開始？** 著明な低Kでは危険で、K安全を先に確保する。
4. **ICU全例をtight glucose control？** hypoglycemiaを避けるprotocolized controlが中心。
5. **shock中のfinger-stickを絶対視？** perfusion等で誤差があり、疑わしければlab確認する。
6. **adrenal crisisはcortisol結果待ち？** severe suspicionでは採取可能なら採取し、治療を待たない。
7. **thyroid stormはTSH値で決まる？** 臓器decompensationと臨床像で診断する。
8. **heat strokeは解熱薬でよい？** 迅速なphysical coolingと臓器supportが中心。
