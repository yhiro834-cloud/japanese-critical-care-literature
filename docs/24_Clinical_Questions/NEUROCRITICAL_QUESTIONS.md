# Neurocritical Care — Clinical Questions

1. **GCSは合計点だけでよいか。** いいえ。E/V/M component、挿管等の制約、左右差、刺激条件、trendを記録する。
2. **CPPの式と限界は。** `CPP = MAP − ICP`。測定level、CVP、autoregulation、局所/全身病態を含め個別化する。
3. **ICP上昇時にPaCO₂を下げ続ければよいか。** いいえ。過換気はCBF低下/ischemia riskがあり、herniationへの短時間bridge等に限定して目的を明示する。
4. **けいれんが止まればstatus終了か。** NCSEが継続し得る。意識回復とEEG適応を評価する。
5. **aSAHの意識悪化をDCIと断定できるか。** fever、Na、seizure、hydrocephalus、sedation、再出血等を除外しmultimodal評価する。
6. **心停止後72時間で覚醒しなければ回復不能か。** いいえ。timing、rewarming、交絡、multimodal findings、不確実性を評価する。
