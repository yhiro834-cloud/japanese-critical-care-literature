# Trauma / Burns — Clinical Questions

1. **eFAST陰性なら腹腔内出血なし？** いいえ。早期、少量、後腹膜、腸管損傷等を除外せず、機転・生理・serial examを統合する。
2. **初期Hb正常なら大量出血なし？** いいえ。急性期の単発値で除外できない。
3. **低血圧外傷はまずCT？** unstableなら蘇生とdefinitive hemorrhage controlへの最短経路を優先する。
4. **permissive hypotensionは全例？** いいえ。TBI、妊娠等では目標が異なり、施設protocolと併存病態で決める。
5. **MTPは開始後そのまま続ける？** いいえ。出血制御、検査、体温、灌流を再評価し、停止/移行条件を共有する。
6. **熱傷輸液式は投与量の答え？** いいえ。開始点であり、尿量を含む多面的な反応とfluid toxicityで調整する。
7. **SpO₂正常ならCO中毒なし？** いいえ。曝露機転とco-oximetry等で評価する。
8. **小範囲熱傷なら専門相談不要？** 部位、深さ、吸入/化学/電撃、circumferential、併存症でも判断する。
