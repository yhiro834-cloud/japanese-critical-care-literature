# Hemodynamics — Clinical Questions

1. **Fluid responsiveならfluidを投与すべきか。** いいえ。needとtolerance、期待する臨床benefitを別に評価する。
2. **CVPの役割は。** 右房圧近似と波形/trend。単一値でvolumeやresponsivenessを決定しない。
3. **PLRの利点は。** 可逆的preload challenge。real-time SV/CO測定が必要。
4. **POCUSでIVCが小さい意味は。** 文脈依存でhypovolemia確定ではない。呼吸、圧、RV、他所見を統合する。
5. **pressor増量にMAPが反応しない時は。** delivery system、測定、phenotype、出血/閉塞、acidosis等を再評価する。
6. **de-resuscitation開始の考え方は。** shock安定後、fluid蓄積による臓器障害と除去toleranceを評価する。
