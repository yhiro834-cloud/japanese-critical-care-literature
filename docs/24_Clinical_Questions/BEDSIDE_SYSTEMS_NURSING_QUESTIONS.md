# Bedside Systems / Nursing — Clinical Questions

1. **monitor値異常ならまず設定？** 患者/pulse/perfusionを先に確認する。
2. **SpO₂ pleth不良ならalarm無視？** 患者評価とindependent confirmationを行う。
3. **A-lineとcuff不一致はどちらが正しい？** leveling/damping/siteと患者を確認する。
4. **alarm resetで復旧？** 原因とpatient responseを確認する。
5. **deviceは機能中なら必要？** indication/removal criteriaを毎日再評価する。
6. **transportはbattery表示だけ確認？** oxygen/power/backup/route/receiving hookupをbriefする。
7. **看護handoffは直近値だけ？** trajectory、intervention response、contingencyを伝える。
8. **終末期はmonitoringを続けるほど安全？** goalsとcomfortに合う情報だけへ簡素化する。
