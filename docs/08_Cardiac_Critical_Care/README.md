# 08 Cardiac Critical Care

## 推奨学習順序

1. [急性冠症候群](ACS/ACUTE_CORONARY_SYNDROME.md)で虚血、ECG、再灌流と合併症を学ぶ。
2. [急性心不全・心原性shock](Heart_Failure_Shock/ACUTE_HEART_FAILURE_CARDIOGENIC_SHOCK.md)でうっ血と低灌流を区別する。
3. [不安定な不整脈](Arrhythmias/UNSTABLE_ARRHYTHMIAS.md)でpulse・不安定性・同期/非同期shockを学ぶ。
4. [心停止・心拍再開後管理](Cardiac_Arrest/CARDIAC_ARREST_POST_ARREST.md)でCPRからROSC後管理までをつなぐ。
5. 昏睡患者の予後評価は[Neuroprognostication](../04_Neurology/Neuroprognostication/NEUROPROGNOSTICATION.md)へ進む。

各章は日本語を主とし、国際algorithmや多職種連携に必要な英語・略語を初出時に説明する。
