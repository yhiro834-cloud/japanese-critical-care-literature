# Acute Heart Failure and Cardiogenic Shock

## Phenotype before reflex treatment

急性心不全はcongestionとperfusionの組合せで評価し、原因/trigger（ACS、arrhythmia、valve/mechanical complication、infection、hypertension、medication、PE等）を同時に探す。cardiogenic shockは低血圧だけでなく、心原性の低灌流と臓器障害のtrajectoryで認識する。

## Bedside integration

- clinical: mentation、skin、JVP、lung、edema、urine、pulse pressure
- ECG、serial lactate/renal/liver、troponin/BNP context
- echo/POCUS: LV/RV、valve、pericardium、volume tolerance; 単一EF/IVCで結論しない
- refractory/uncertain shockではinvasive hemodynamicsを含む高度評価をshock teamと検討

## Treatment logic

```text
congestion? + hypoperfusion?
→ oxygen/ventilation need and precipitant
→ BP/perfusion adequate: diuresis/vasodilation phenotype
→ hypoperfusion/shock: cautious preload test only if indicated
   + vasoactive support + urgent cause control/revascularization
→ serial response → shock team / transfer / selected temporary MCS
```

> [!CAUTION]
> 肺水腫や高JVPにblind fluidを行わない。逆にRV infarction、tamponade等を一律利尿で悪化させない。MCSはdeviceを先に選ぶのではなく、shock phenotype、可逆性、timing、exit strategy、合併症を多職種で評価する。

## Vasoactive and device safety

vasopressor/inotropeはMAPだけでなくflow、congestion、arrhythmia、lactate、末梢/臓器灌流への反応で最小有効量を調整する。詳細は[vasoactive SSOT](../../03_Circulation/Vasoactive_Medications/VASOPRESSORS_INOTROPES.md)。temporary MCSの詳細はPhase 12の[ECMO/MCS](../../09_ECMO_MCS/README.md)へ接続する。

## Nursing surveillance

呼吸仕事量、rhythm、A-line waveform、末梢灌流、尿量、体重、fluid balance、electrolytes、renal/liver trend、vasoactive lineを追う。新規murmur、pulse loss、急な肺水腫、recurrent VT、lactate/尿量悪化、薬剤需要増加はshock escalation。
