# 全カテゴリー・イラスト整備計画

## 完成条件

各カテゴリーを「文章だけ」または「生成画像だけ」で完成とはしない。カテゴリー入口と主要SSOTについて、用語の正式名称、初心者向けの意味、経験者向けの限界、関連する解剖・病態・機器図、再評価点、根拠への接続が揃った時点で完成とする。

## 分担原則

- 解剖・臓器・一般的な外観：高精細ラスターイラスト。
- 血流、ガス、薬液、回路方向、判断手順：検証可能なSVG。
- 日本語ラベル、略語の正式名称、数値、注意事項：本文またはSVGで管理。
- 製品ごとに異なる機器：一般図で操作を教えず、取扱説明書と施設手順へ接続。
- 生成案に解剖・接続の疑義があれば、見栄えが良くても不採用。

## 現時点の採用判断

- 採用：気道・人工呼吸器、心肺循環、頭蓋内、腎・尿路・腎単位、肝胆膵・門脈、一次・二次止血、内分泌臓器。
- 不採用：生成AI単独のCRRT・ECMO回路図、境界が不正確な熱傷深度図。
- 理由：回路方向や深度判断が安全性に直結する領域では、見た目より検証可能性を優先するため。
