# Vasopressors and Inotropes

> [!CAUTION]
> vasoactive薬は高リスク持続静注薬です。濃度・投与経路・titration・最大量は施設protocolと処方を優先し、本頁を用量表として使用しないでください。extravasation、ischemia、arrhythmia、急な中断に備えます。

## 0. まず覚える

**昇圧薬（vasopressor）**は主に血管toneを高めて圧を支え、**強心薬（inotrope）**は主に心収縮を支える薬です。実際の作用は重なります。

**簡単に言うと：** 血圧を上げる薬ではなく、循環破綻の原因に合わせて圧・flow・灌流を支える高リスク薬です。

**新人看護師の到達点：** 薬剤名、濃度、投与経路、pump、接続、目標、titration指示を確認し、血圧・調律・末梢循環・尿量・漏出を監視すること。

**ベテラン向け深掘り：** receptor作用だけでなく、shock phenotype、CO、afterload、RV、arrhythmia、末梢/腸管/皮膚灌流、dose escalationの原因を評価します。

### 報告例

> 「薬剤○、濃度○、速度○、経路○です。MAP○に対し○分で増量○回、意識・CRT・尿量・lactate・調律は○○です。line接続と漏出は○○、必要量が増える原因を○○まで確認しています。」

## 1. Overview

vasopressorは主にvascular tone/MAP、inotropeはcontractility/COを変えますが、多くは混合作用を持ちます。薬剤選択は「低血圧」という数字でなく、vasoplegia、LV/RV dysfunction、HR/rhythm、冠/末梢灌流、原因治療と統合します。

## 2. Agents as Physiologic Tools

| Agent | 主な作用の臨床像 | 主な監視/害 |
|---|---|---|
| Norepinephrine | α優位＋β作用、vasoplegiaでのpressure support | tachyarrhythmia、ischemia、afterload、extravasation |
| Vasopressin | V1-mediated vasoconstriction、catecholamine-sparing | digital/mesenteric ischemia、低Na等。固定/調整法はprotocol依存 |
| Epinephrine | β＋α、inopressor | tachyarrhythmia、lactate上昇、hyperglycemia |
| Dobutamine | β優位inotropy/inodilation | hypotension、tachyarrhythmia、虚血 |
| Milrinone | PDE3 inhibition、inodilation | hypotension、arrhythmia、腎機能による蓄積 |

薬理はdose、患者、併用薬で変化します。phenylephrine等も特定文脈で用いますが、万能な「次の順番」はありません。

## 3. Initiation and Monitoring

- shock原因治療、volume need/tolerance、targetを同時に定義
- life-threatening hypotensionでは安全な末梢routeから早期開始する場合があるが、site、catheter、濃度、観察、central transitionをprotocol化
- arterial pressure、ECG、perfusion、urine、lactate、CO/SV、echo、skinを監視
- increase後にexpected responseがなければ、line/pump/concentration、phenotype、occult bleeding/obstruction、acidosis、adrenal/薬剤要因を再評価

SSC 2026ではseptic shockの薬剤選択がcardiac dysfunctionの有無で分岐し、persistent hypoperfusion despite adequate fluid status and arterial pressureではinotropeを提案します。inotropeは必要なvasopressorの代替ではありません。

## 4. Clinical Reasoning

```text
hypotension + hypoperfusion → SVR/CO phenotype → targetを個別化
→ agentを機序で選択 → line/pumpを安全確認
→ MAPだけでなくCO/perfusion/害を再評価
→ 反応なしなら増量反復前に原因とdeliveryを再確認
→ 回復時は急中断せず、end-organ responseを見ながらwean
```

## 5. Nursing Points

- drug、concentration、weight basis、route、pump library、line traceをdouble-check
- dedicated lumen、接続、dead space、carrier flow、残量、battery、搬送予備を確認
- peripheral infusion siteを頻回観察し、pain/blanching/swelling時は即時extravasation protocol
- syringe/bag交換時のinterruption/bolusを防ぎ、変更前後のBP/HRを記録
- distal perfusion、rhythm、glucose/lactate、urine、skinを報告

## 6. Red Flags / Pitfalls

- 急な血圧低下：empty syringe、closed clamp、disconnection、infiltration、concentration error
- MAPだけを追ってCO/末梢虚血を悪化、pressor escalationで出血/閉塞を隠す
- line dead spaceによる反応遅延、急なflush/bolus、abrupt discontinuation

## 7. Take Home Messages

1. vasoactive薬はshock phenotypeへのphysiologic intervention。
2. responseはMAP、flow、tissue perfusion、害で判定する。
3. delivery systemの安全は薬剤選択と同じくらい重要。
