# Shock: Recognition and Phenotype

> [!CAUTION]
> 教育目的の資料です。Shockは時間依存性の生命危機です。個別患者では院内急変対応、最新ガイドライン、施設protocol、担当チームの判断を優先してください。

## 0. まず覚える

**ショック（shock）**は、組織が必要とする酸素と栄養を血流で届けられず、臓器障害へ進む生命危機です。低血圧は重要ですが、血圧が保たれた早期shockもあります。

**簡単に言うと：** 血圧の数字ではなく、脳・皮膚・腎などへ血流が届いているかを見ます。

| 用語 | 意味 | 看護で見ること |
|---|---|---|
| perfusion | 組織灌流 | 意識、CRT、皮膚、尿量、lactate、臓器機能 |
| MAP | 平均動脈圧 | 測定品質と灌流反応を合わせる |
| CO | 心拍出量 | 1分間に心臓が送り出す血液量 |
| phenotype | 循環破綻の型 | preload、pump、tone、obstructionと混合型 |

**新人看護師の到達点：** 意識、皮膚、CRT、脈、血圧、尿量、呼吸を同時に確認し、変化時刻・介入・反応を報告すること。

**ベテラン向け深掘り：** pressure、flow、perfusionを分け、混合shock、右心、微小循環、測定誤差、介入による害を再評価します。

### 報告例

> 「○時から血圧○、MAP○ですが、意識、CRT、皮膚、尿量、lactateは○○です。心拍・調律、呼吸、出血/感染所見は○○、介入○○後の反応は○○です。」

## 1. Overview

Shockは「血圧が低い状態」ではなく、循環が組織の酸素・基質需要を満たせず、細胞・臓器障害が進む臨床症候群です。正常血圧でも起こり、低血圧でも組織灌流が保たれる場面があります。

## 2. Why It Matters

原因治療が遅れるほど、低灌流、内皮障害、炎症、微小循環障害、臓器障害が互いを増幅します。最初の役割は病名を完全に確定することではなく、Shockを認識し、生命危機へ対処しながら循環表現型を更新することです。

## 3. Physiology

- `MAP ≈ CO × SVR`（右房圧を無視した概念式）
- `CO = HR × SV`
- SVは前負荷、収縮力、後負荷、心室相互作用に影響される
- `DO₂ = CO × CaO₂`
- CaO₂は主にHbとSaO₂で決まり、PaO₂の寄与は小さい

したがって、MAPだけではCO、Hb、SaO₂、酸素抽出、微小循環を説明できません。

## 4. Pathophysiology

| 主表現型 | 主な破綻 | 典型例 | ベッドサイドの手掛かり（単独で確定不可） |
|---|---|---|---|
| Distributive | 血管緊張低下、血流分布・微小循環異常 | sepsis、anaphylaxis、neurogenic | warm extremities、wide pulse pressure、低SVR |
| Hypovolemic | 循環血液量・静脈還流低下 | 出血、脱水、third spacing | narrow pulse pressure、flat neck veins、fluid responsiveの可能性 |
| Cardiogenic | pump failure | AMI、myocarditis、acute MR | 肺うっ血、冷感、echoで収縮/弁異常 |
| Obstructive | 心充満または駆出の機械的障害 | PE、tamponade、tension pneumothorax | 頸静脈怒張、右心負荷、左右呼吸音差など |

混合性が多く、septic cardiomyopathy、陽圧換気、出血、鎮静薬などで表現型は時間とともに変わります。

## 5. Causes / Etiology

ABCDEで見逃すと直ちに致命的な原因（大量出血、緊張性気胸、心タンポナーデ、重症アナフィラキシー、致死性不整脈等）を先に探します。同時に感染、心筋虚血、薬剤、内分泌、体液喪失を評価します。

## 6. Assessment

### 第一印象

- 意識・会話、呼吸仕事量、皮膚色、発汗、体位
- pulse、NIBPを再測定し、cuff/測定部位/不整脈の影響を確認
- CRT、末梢温、mottling
- 尿量と時間推移

### ABCDE

- **A/B:** 低酸素・換気障害・高胸腔内圧は循環を悪化させる
- **C:** 出血、pulse、MAP、CRT、皮膚、尿量、lactate、ECG、POCUS
- **D:** 意識変容は脳灌流低下、低酸素、低血糖、薬剤などを鑑別
- **E:** 発熱/低体温、rash、感染源、外傷、drain、出納

## 7. Monitoring

- 連続ECG、SpO₂、頻回血圧
- 意識、CRT、皮膚、末梢温、尿量のtrend
- lactateは採血条件と推移を含める
- Hb、ABG/VBG、電解質、腎肝機能、凝固
- 介入前後のecho/POCUS（画像だけでなく臨床文脈と統合）
- vasopressor増量中、複数使用、測定不一致ではA-lineを検討

## 8. Interpretation

### MAP

臓器灌流圧の代替指標です。個別の自己調節域、慢性高血圧、腹腔内圧、静脈圧を反映しないため、目標到達を蘇生完了としません。

### Lactate

高値は低灌流を示唆しますが、β刺激、解糖亢進、肝クリアランス低下、痙攣などでも上昇します。正常化を目的に無制限に輸液せず、原因とtrendを解釈します。

### CRT

簡便で反復可能ですが、測定部位、圧迫時間、室温、照明、末梢血管疾患、観察者差の影響を受けます。手技をそろえてtrendを見ます。

### Urine output

腎灌流の手掛かりですが、閉塞、CKD、薬剤、ADH、利尿薬でも変化します。短時間の単独値では判断しません。

## 9. Diagnosis

Shockに単一の診断検査はありません。循環不全を示す臨床所見と臓器障害を統合し、原因・表現型を並行して診断します。

## 10. Clinical Reasoning

```text
低血圧または灌流不良を疑う
→ 測定は正しいか／直ちに治療すべき原因はあるか
→ 本当に組織灌流障害か（意識・CRT・皮膚・尿量・lactate）
→ COは不足していそうか
→ HR・前負荷・収縮力・後負荷・閉塞のどこか
→ distributive / hypovolemic / cardiogenic / obstructive / mixed
→ 最小限の安全な介入と原因治療
→ 同じ指標で反応と害を再評価
→ 仮説を更新
```

### Fluid responsivenessを治療適応と混同しない

SVが輸液で増える可能性があっても、輸液が必要・安全とは限りません。「反応するか」「灌流改善が必要か」「fluid toleranceがあるか」を分けます。

## 11. Treatment

1. 応援要請、monitoring、酸素化/換気、vascular access
2. 出血・閉塞・感染源・アナフィラキシー等の原因治療
3. 表現型に合う循環支持（fluid、vasopressor、inotrope、血液製剤等）
4. 介入ごとに反応と害を確認

固定量や単一MAPを全Shockへ適用しません。薬剤・輸液の詳細は各SSOTページと施設protocolを参照します。

## 12. Nursing Points

- monitor alarmより先に患者を直接評価
- 血圧測定の信頼性を確認し、trendと投薬変更を時系列で記録
- vasopressor lineの接続、濃度、投与経路、残量、閉塞、extravasationを確認
- fluid/輸血後は呼吸、SpO₂、肺音、浮腫、酸素需要も再評価
- 尿量低下時はcatheter屈曲・閉塞・膀胱充満を確認
- escalation時は「いつから・何が変化・介入・反応・懸念」を伝える

## 13. ICU Nursing Pearls

- 「MAP 65」は患者評価の終点ではない
- 介入前の値を残すと反応性を評価できる
- dose escalationは病態悪化だけでなくline/調製/測定の問題でも起こる
- warm shockでも重篤な低灌流はあり得る

## 14. Red Flags

- 急速な意識悪化、mottling/cyanosis、CRT延長
- 持続または進行する低血圧
- 胸痛、ST変化、致死性不整脈
- 呼吸音左右差、急な気道内圧上昇、頸静脈怒張
- 活動性出血、Hb急低下
- lactate上昇が続く、無尿
- vasopressor requirementの急増

## 15. Troubleshooting

**患者 → 測定 → line/薬剤 → preload/pump/afterload/obstruction → 原因治療 → 再評価**の順で確認します。機器異常を疑っても患者評価とbackupを先行します。

## 16. Common Pitfalls

- hypotension = shock、正常血圧 = shockなし、と決める
- CVPやIVC径の単独値で輸液を決める
- lactate正常化まで輸液を続ける
- MAP上昇だけを成功とする
- 初期表現型を固定し再評価しない

## 20. Take Home Messages

1. Shockは血圧ではなく組織灌流不全として捉える。
2. MAP、CRT、lactate、尿量、意識を単独でなくtrendで統合する。
3. COをHR・前負荷・収縮力・後負荷・閉塞へ分解して考える。
4. 表現型は混合し、時間と介入で変化する。
5. すべての介入に「期待する反応・害・再評価」を設定する。
