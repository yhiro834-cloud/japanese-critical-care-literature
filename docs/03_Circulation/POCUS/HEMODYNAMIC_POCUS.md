# Hemodynamic POCUS

> [!CAUTION]
> POCUSはfocused questionへのbedside testであり、training、画像品質、保存、報告、QAを要します。poor windowや正常に見える限定画像で重大病態を除外せず、必要ならformal echocardiography/CT等へescalateしてください。

## 0. まず覚える

**point-of-care ultrasound（POCUS）**は、担当clinicianがベッドサイドで焦点を絞った問いに答える超音波検査です。

**簡単に言うと：** 「心臓を一度見る検査」ではなく、患者のshock仮説を確かめ、介入後に同じ条件で見直す検査です。

| 用語 | 意味 | 限界 |
|---|---|---|
| focused question | 具体的な臨床上の問い | 漠然と全疾患を除外できない |
| view | probe位置ごとの標準画像 | poor windowを正常と扱わない |
| VTI | 血流速度時間積分 | SV trendの手掛かり。測定再現性が必要 |
| IVC | 下大静脈 | 単独でvolumeや輸液適応を決めない |

**新人看護師の到達点：** 検査目的、体位、血圧・呼吸器条件、line/tube安全、感染対策を確認し、結果を問い・quality・限界とともに共有すること。

**ベテラン向け深掘り：** LV/RV、心嚢、肺、静脈うっ血、VTI responseをpressure・flow・perfusionへ統合し、不一致時は上位検査へつなぎます。

## Visual：肺POCUS artifact

[肺POCUS artifactの模式図](../../../assets/pocus/lung_ultrasound_schematic.svg)は、胸膜線/A-line、B-line、胸水、consolidationの概念を比較します。実際の超音波画像ではなく、artifactと病名を一対一対応させないための導入図です。実技は認定された教育、実機、画像保存、supervision、QAで学びます。

## 1. Overview

ESICM 2025はshock typeを評価するfirst-line imagingとしてechocardiographyを推奨し、SCCM 2024はcardiogenic shockやtargeted volume management等でCCUSを提案しています。POCUSは「volume status測定器」でなく、心・肺・静脈・腹部を臨床文脈に統合する反復検査です。

## 2. Focused Questions

- LV/RV sizeとgross systolic function、regional abnormalityの示唆
- pericardial effusionとtamponade physiology
- RV pressure/volume overload、massive PEを示唆するpattern（単独確定ではない）
- lung B-lines、pleural sliding、consolidation、effusion
- aorta/abdomen/free fluidを適応に応じ評価
- VTI/SV trendでPLRや介入反応を測る
- venous congestionはIVC単独でなくhepatic/portal/renal venous pattern等を文脈化

## 3. Acquisition and Interpretation

indicationと事前確率を明示し、標準view、orientation、depth/gain、ECG、複数cycleを確認します。画像を保存し、view/quality/limitation/answerを報告します。mechanical ventilation、PEEP、arrhythmia、胸腔/腹腔圧、valve diseaseが解釈へ影響します。

## 4. Clinical Reasoning

```text
shock → focused question → adequate viewを複数取得
→ LV/RV/pericardium/lung/volume toleranceを統合
→ phenotype仮説 → targeted intervention
→ 同じ測定条件でPOCUS + perfusion + pressure/flowを再評価
→ 不一致/poor qualityなら上位検査
```

## 5. Nursing / Team Points

- probe、machine、感染対策、patient position、line/tube safetyを準備
- POCUS中の血圧/SpO₂/体位/ventilator条件を記録
- 結果を「IVC flat」だけでなく、問い・quality・全体結論・limitationとしてhandoff
- serial studyの時刻と介入を対応させる

## 6. Red Flags / Pitfalls

- tamponade、severe RV dilation with shock、new severe LV dysfunction、aortic catastrophe示唆
- IVCだけで輸液、B-linesだけで心原性と確定、incidental findingの過剰診断
- image保存/QAなし、poor windowをnegative studyと記載

## 7. Take Home Messages

1. POCUSはfocused questionとshock phenotypeのために使う。
2. IVC単独でfluidを決めない。
3. image qualityと限界を記録し、介入後に再評価する。
