# 03 Circulation

循環生理、shock、組織灌流、血行動態、fluid responsiveness、輸液/輸血、vasopressor/inotrope、POCUSを扱います。

## 新人看護師の読み順

1. [Shock](Shock/SHOCK.md)：血圧ではなく組織灌流から考える
2. [血行動態monitoring](Hemodynamics/HEMODYNAMIC_MONITORING.md)：pressure・flow・perfusionを分ける
3. [輸液療法](Fluid_Therapy/FLUID_THERAPY.md)：目的・反応・停止条件・蓄積した害
4. [昇圧薬・強心薬](Vasoactive_Medications/VASOPRESSORS_INOTROPES.md)：薬剤deliveryと灌流を監視
5. [敗血症性shock](Shock/SEPTIC_SHOCK.md)：感染治療と循環蘇生のtimeline
6. [循環POCUS](POCUS/HEMODYNAMIC_POCUS.md)：問い・画像品質・限界・再評価

## ベテラン看護師の学習焦点

- MAP達成を蘇生終了とせず、CO/SV、CRT、意識、尿量、lactate、臓器機能を統合する。
- fluid responsivenessとfluidが必要・安全であることを区別する。
- preload、pump、tone、obstructionの混合型と治療による表現型変化を追う。
- monitor、POCUS、検査値が不一致のときに測定条件と仮説を再検討する。
