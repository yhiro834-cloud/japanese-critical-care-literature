# Fluid Therapy: Resuscitation to De-escalation

> [!CAUTION]
> fluidは薬剤です。種類、量、速度、目的、response、stop criteria、蓄積した害を処方単位で考えます。shock phenotypeにかかわらず一律量を投与しないでください。

## 0. まず覚える

**輸液療法（fluid therapy）**は、血管内へ液体を投与し、循環や水分・電解質を支える治療です。

**簡単に言うと：** 「入れること」ではなく、目的を決め、少量ごとに反応と害を確認し、不要になれば止めて蓄積を減らすprocessです。

| 用語 | 意味 | 注意 |
|---|---|---|
| fluid bolus | 短時間に投与し反応を見る輸液 | 目的、量、速度、停止条件を共有 |
| responsiveness | 輸液でflowが増える可能性 | benefitや必要性と同義ではない |
| fluid balance | 一定期間のin−out | 体重、浮腫、肺、腎、測定誤差と統合 |
| de-resuscitation | 安定後に余剰水分を減らす段階 | perfusionと循環安定性を監視 |

**新人看護師の到達点：** 輸液の種類・目的・量・速度・開始時刻を確認し、血圧だけでなく呼吸、尿量、皮膚、浮腫、介入反応を記録すること。

**ベテラン向け深掘り：** fluid tolerance、右心/左心、肺水分、腎、chloride、累積balance、vasopressorとのtrade-offを評価します。

## 1. Overview

fluid managementはrescue/resuscitation、optimization、stabilization、de-escalationの時間軸で変わります。必要な初期resuscitationを遅らせず、同時にfluid overload、肺水腫、静脈うっ血、腹腔内圧、腎/組織浮腫を避けます。

## 2. Choice of Fluid

ESICM Part 1（2024）は対象病態ごとにcrystalloid、balanced solution、saline、albumin等を比較します。fluidの選択は電解質/酸塩基、脳損傷、出血、腎、肝、製剤risk、可用性で異なります。hydroxyethyl starch等の合成colloidをroutine resuscitationの標準にしません。血液製剤は単なるvolume expanderでなく、出血/凝固/酸素運搬の別問題として扱います。

## 3. Volume and Response

ESICM Part 2（2025）は、病態別にliberal/restrictive strategyの確実性と限界を示します。左心系cardiogenic shockではfluidをprimary treatmentにしないなど、phenotypeが重要です。

fluidを投与する前に確認します。

1. **Need:** hypoperfusionがありpreload不足が寄与し得るか
2. **Responsiveness:** SV/COが増えそうか
3. **Tolerance:** 肺水腫、RV failure、静脈うっ血、腹腔内圧に耐えられるか
4. **Test:** 種類、量、時間、測定法
5. **Stop:** responseなし、うっ血/酸素化/圧悪化、目標達成

## 4. De-escalation / Fluid Removal

shockが安定しfluid蓄積が臓器機能を妨げる場合、自然排泄、利尿、RRT ultrafiltration等を検討します。ESICM Part 3（2025）はde-escalationを独立phaseとして扱います。除去は循環、腎機能、electrolytes、perfusion、refillingを監視し個別化します。

## 5. Clinical Reasoning

```text
hypoperfusion → phenotype/出血/閉塞を同時評価
→ fluidが機序を改善するか → PLR等でresponsiveness
→ toleranceを肺/RV/静脈うっ血で確認
→ defined challenge → SV/CO + perfusion + harmを再評価
→ 安定後はmaintenance/hidden fluidsを削減 → de-escalation
```

## 6. Nursing Points

- bolus/challengeのfluid種類、量、時間、開始前後のSV/CO/BP/CRT/呼吸を記録
- carrier、drug diluent、nutrition、flushを含むhidden fluidを日次集計
- input/output、体重、浮腫、lung sounds/oxygen、abdominal pressure risk、skinをtrend評価
- electrolyte、chloride、acid–base、glucose、temperature、製剤副作用を監視
- fluid orderに目的/再評価がなければチームへ確認

## 7. Red Flags / Pitfalls

- oxygenation悪化、B-lines/肺水腫、RV dilation/静脈うっ血、腹圧上昇、希釈性coagulopathy
- “腎保護”目的の無反応な追加輸液、尿量だけを目標、resuscitation終了後もmaintenance継続
- responsivenessをbenefitと同一視、cumulative balanceを見ない

## 8. Take Home Messages

1. fluidはphaseとphenotypeで処方する。
2. need × responsiveness × toleranceを分ける。
3. stabilization後はhidden fluid削減とde-escalationを検討する。
