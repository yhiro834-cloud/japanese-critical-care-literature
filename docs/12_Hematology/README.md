# 12 Hematology

## 推奨学習順序

1. [輸血とPatient Blood Management](Transfusion/TRANSFUSION_PBM.md)で製剤選択と輸血反応を学ぶ。
2. [DICと急性血小板減少](DIC_Thrombocytopenia/DIC_THROMBOCYTOPENIA.md)で出血・血栓と鑑別を学ぶ。
3. [抗凝固・拮抗・VTE](Anticoagulation_VTE/ANTICOAGULATION_REVERSAL_VTE.md)で薬剤照合、緊急拮抗、再開判断を学ぶ。

各章は単一の検査閾値でなく、出血・血栓・臓器障害・手技・治療後反応を統合する構成にしている。
