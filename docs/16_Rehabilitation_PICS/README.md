# 16 Rehabilitation and PICS

## 推奨学習順序

1. [早期離床とICU-acquired weakness](Early_Mobility/ICU_EARLY_MOBILITY.md)で毎日の活動処方と安全評価を学ぶ。
2. [PICS / PICS-Fと回復](PICS/PICS_RECOVERY.md)でICUから自宅までの身体・認知・精神・家族支援を学ぶ。

回復は退院時に始めるのではなく、ICUでの鎮痛、鎮静、睡眠、栄養、communication、患者参加から始める。
