# 人工呼吸器の基本用語

> [!CAUTION]
> 用語を知ることと設定を変更できることは同じではありません。設定変更は患者の病態、測定条件、循環、施設手順、担当チームの方針を確認して行います。急変時は画面より患者を先に評価します。

## まず全体像

人工呼吸器は、酸素化、二酸化炭素排出、呼吸仕事量を支えます。画面の値は「患者・人工気道・回路・人工呼吸器」が一体となった結果です。1つの値だけで原因を決めません。

## PEEPとは

**呼気終末陽圧（positive end-expiratory pressure：PEEP）**は、息を吐き終わった時点でも気道内圧を大気圧より高く保つための圧です。

**簡単に言うと：** 呼気の終わりに肺胞が閉じにくいよう、気道に残しておく圧です。

### なぜ使うのか

- 呼気終末の肺胞虚脱を抑え、再開通と再虚脱の反復を減らす可能性がある。
- 換気に参加する肺胞が増えれば、酸素化が改善することがある。
- 同じPEEPでも、開きやすい肺胞と過膨張しやすい肺胞が混在するため反応は患者ごとに異なる。

### 3つのPEEPを区別する

| 用語 | 意味 | ポイント |
|---|---|---|
| 設定PEEP | 人工呼吸器に設定したPEEP | 画面上の設定値 |
| auto-PEEP | 呼気が終わる前に次の吸気が始まり、肺内に残った内因性の圧 | 呼気flow、呼気時間、抵抗、患者努力を確認 |
| PEEPtotal | 呼気終末に実際に存在する総PEEP | 設定PEEPとauto-PEEPを含む概念 |

### 新人看護師が見ること

1. SpO₂だけでなく、呼吸努力、呼吸音、胸郭運動、意識、皮膚色を確認する。
2. 血圧、心拍数、尿量、末梢循環を確認する。PEEP上昇で静脈還流が減り、循環が悪化することがある。
3. 設定変更前後の時刻、FiO₂、PEEP、SpO₂、血圧、患者所見を同じ流れで記録する。
4. 呼気flowが次の吸気前に基線へ戻るか、患者が吸いにくそうでないかを確認する。

### 高すぎる、または患者に合わない可能性を考える所見

- 新たな血圧低下、頻脈、末梢循環悪化
- 気道内圧上昇、肺過膨張を疑う所見、換気悪化
- 片側呼吸音低下、急な酸素化・循環悪化など気胸を疑う所見
- 右心負荷・静脈還流低下が問題となる臨床状況

これらはPEEPだけが原因とは限りません。患者、airway、回路、人工呼吸器、病態を順に確認し、緊急性があれば直ちに応援を要請します。

### ベテラン向け深掘り

PEEPによるrecruitment、overdistension、肺血管抵抗、右室afterload、静脈還流への影響は同時に起こり得ます。酸素化の改善だけを利益とみなさず、driving pressure、compliance、dead space、血圧、右心、臓器灌流、患者努力の変化を統合します。ARDSにおけるhigher PEEPは対象集団と戦略に依存する条件付き推奨であり、「すべての患者で高いほどよい」という意味ではありません。

## Ppeakとは

**最高気道内圧（peak inspiratory pressure：Ppeak）**は、吸気中に気道入口で観測される最も高い圧です。

**簡単に言うと：** 気体を流しながら肺へ送るときに必要だった圧の最大値です。

Ppeakは、気道抵抗、吸気flow、肺・胸壁の弾性、PEEP、患者努力などの影響を受けます。高値なら分泌物、気管支攣縮、tube屈曲、回路、肺・胸壁病態をPplatと患者所見で分けます。

## Pplatとは

**プラトー圧（plateau pressure：Pplat）**は、吸気終末にholdを行い、flowが0となった条件で測る静的な気道内圧です。

**簡単に言うと：** 気体の流れによる抵抗成分を減らし、肺・胸壁を膨らませている圧を推定する値です。

患者努力、leak、不十分なholdがあると誤読します。数値を見る前にpressure・flow波形と測定条件を確認します。

## Driving pressureとは

**駆動圧（driving pressure）**は通常、`Pplat − PEEPtotal`で表します。

**簡単に言うと：** 1回の換気で呼吸器系を呼気終末の状態から膨らませるために加わる圧差です。

静的complianceと関係しますが、単独の目標値や安全保証として使いません。患者努力、胸壁、PEEP測定条件を含めて解釈します。

## Complianceとresistance

**コンプライアンス（compliance：伸展性）**は、圧の変化に対して肺・胸壁がどれだけvolumeを変えられるかを表します。低下すると、同じVTを入れるためにより高い弾性圧が必要になります。

**気道抵抗（airway resistance）**は、気体が気道、気管tube、回路を流れる際の通りにくさです。一定flow条件ではPpeak−Pplatが抵抗成分の手掛かりになります。

## FiO₂、VT、RR

- **FiO₂（吸入酸素濃度）:** 吸う気体中の酸素割合。SpO₂やPaO₂だけでなく、必要なFiO₂のtrendを確認します。
- **VT（一回換気量）:** 1回の呼吸で出入りする気体量。設定値と呼気実測値、予測体重、leak、pressureを区別します。
- **RR（呼吸数）:** 1分間の呼吸回数。設定回数、実測回数、患者の自発呼吸、深さ、努力を区別します。

## ベッドサイドで用語を値に結びつける

```text
患者の見た目と生命徴候
→ airway・回路・接続
→ modeと設定値
→ 実測値と3つの時間波形
→ 前回からのtrend
→ 仮説を共有
→ 介入後に患者・波形・循環を再評価
```

## 報告例

「高圧alarmです」だけでなく、次のように共有します。

> 「2分前からPpeakが上昇しています。Pplatは測定条件を整えて確認中です。SpO₂、血圧、呼吸努力は○○、左右呼吸音は○○、tube位置と回路接続は○○です。吸引前後で○○、波形は○○です。」

未確認項目を確認済みのように言わず、時刻、変化、患者所見、実施した安全確認、反応を伝えます。

## 確認問題

1. 設定PEEP、auto-PEEP、PEEPtotalの違いを説明してください。
2. Ppeak上昇時にPplatを確認する理由は何ですか。
3. PEEP変更後にSpO₂以外で確認する患者所見を3つ挙げてください。
4. 数値が変化したとき、患者・回路・測定条件のどれをどう確認しますか。
