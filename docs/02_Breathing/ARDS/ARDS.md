# 急性呼吸窮迫症候群

> [!CAUTION]
> ARDSはsyndromeです。肺保護と同時に原因診断・治療、循環/RV、fluid balance、感染管理を行います。Berlin定義と新しいglobal definitionは対象・support範囲が異なるため、使用定義を明記してください。

## 0. まず覚える

**急性呼吸窮迫症候群（acute respiratory distress syndrome：ARDS）**は、肺の炎症と透過性亢進により肺水分が増え、肺胞虚脱・shunt・肺の不均一性を生じるsyndromeです。

**簡単に言うと：** 肺全体が同じように硬くなるのではなく、使える肺が小さく不均一になり、酸素化を支えながら人工呼吸による追加損傷を避ける必要があります。

| 用語 | 意味 | 看護で結びつけること |
|---|---|---|
| shunt | 血流はあるが換気されない領域 | 酸素への反応、体位、原因、循環を確認 |
| VILI | 人工呼吸器関連肺傷害 | VT、Pplat、driving pressure、努力、同調性を統合 |
| prone positioning | 腹臥位療法 | tube/line、眼・顔面、皮膚、圧迫、循環、team安全 |
| P/F ratio | PaO₂/FiO₂比 | PEEP、device、体位、時刻とともに解釈 |

**新人看護師の到達点：** FiO₂/PEEP/体位とSpO₂・血液ガスを対応させ、人工気道、波形、血圧、尿量、fluid balance、皮膚を観察すること。

**ベテラン向け深掘り：** recruitability、過膨張、右心負荷、強い自発努力、prone response、fluidと灌流のtrade-off、定義の違いを統合します。

### 報告例

> 「ARDS管理中、現在の体位○、FiO₂○、PEEP○、SpO₂○、直近PaO₂○です。Pplat/呼気VT/波形は○○、血圧・尿量・fluid balanceは○○で、体位または設定変更後に○○へ変化しています。」

## 1. Overview / Pathophysiology

炎症性肺障害によりpermeability edema、surfactant dysfunction、dependent atelectasis、heterogeneous “baby lung”が生じます。同じairway pressureでも局所stress/strainは不均一で、volutrauma、barotrauma、atelectrauma、biotraumaとpatient self-inflicted lung injuryが問題になります。

## 2. Assessment / Diagnosis

- 急性経過、risk factor/insult、両側陰影、心原性/volume overloadだけでは説明できないか
- oxygenationをFiO₂、PEEP/CPAP、体位、support deviceとセットで評価
- Berlin definitionを使う場合、PEEP/CPAP ≥5 cmH₂O下のP/Fで軽症201–300、中等症101–200、重症≤100
- infection、cardiogenic edema、DAH、organizing pneumonia等のalternativeを再評価

## 3. Evidence-based Management

- **強い推奨（既存ATS）:** ARDSでVT 4–8 mL/kg predicted body weightかつPplat <30 cmH₂Oを目指す肺保護換気、severe ARDSで12時間/日を超えるprone positioning
- **ATS 2024 conditional:** corticosteroids、選択されたsevere ARDSでVV-ECMO、early severe ARDSでneuromuscular blockade、moderate–severe ARDSでprolonged recruitment maneuverを伴わないhigher PEEP
- **強い反対推奨:** moderate–severe ARDSでprolonged lung recruitment maneuvers

薬剤、PEEP、筋弛緩、ECMOは選択基準、禁忌、timing、専門体制が必要で、固定recipeにしません。[Mechanical Ventilation](../Mechanical_Ventilation/MECHANICAL_VENTILATION.md)をpressure/mechanicsのSSOTとします。

## 4. Clinical Reasoning

```text
hypoxemic failure + bilateral opacity → timing/risk factor/alternativeを確認
→ lung-protective ventilationと原因治療 → P/FだけでなくWOB/mechanics/RV/循環を評価
→ refractoryならprone、PEEP strategy、選択的adjunctを段階的に検討
→ 各介入後にoxygenationだけでなくpressure、hemodynamics、合併症を再評価
```

## 5. Nursing Points

- PBW計算に身長とsexを正確に記録し、実体重と混同しない
- Pplat/PEEP/VT/FiO₂、position、gas、hemodynamicsの時刻を揃える
- proneはairway/line/drain、眼・顔面、皮膚、腹部、圧迫、鎮静/筋弛緩、emergency return planをchecklist化
- fluid balance、urine output、perfusion、RV strain、VTE/pressure injury/weaknessを監視
- familyへ治療目的と長期回復/PICSを説明するチーム連携

## 6. Red Flags / Pitfalls

- refractory hypoxemia、急なpressure上昇、shock/RV failure、pneumothorax、tube/line displacement
- P/F改善だけを成功とする、prone開始遅延、routine prolonged recruitment、Pplat未測定、PBW誤り

## 7. Take Home Messages

1. ARDSはheterogeneous lungを傷つけず支える戦略が中心。
2. low VT/Pplat limitationとsevere ARDSのproneは強い推奨。
3. adjunctは患者選択と害の監視を伴う。
