# 人工呼吸器離脱と抜管評価

> [!CAUTION]
> SBT合格と抜管可能は同義ではありません。airway protection、cough/secretions、上気道、神経・循環状態、再挿管計画を別に評価します。

## 0. まず覚える

**人工呼吸器離脱（ventilator liberation）**は、人工呼吸supportを減らし、自発呼吸へ安全に移行できるかを毎日評価するprocessです。

**自発呼吸試験（spontaneous breathing trial：SBT）**は、少ないsupportで一定時間呼吸できるかを確認する試験です。

**簡単に言うと：** SBTは「呼吸できるか」の試験であり、抜管はさらに「気道を守り、分泌物を出し、再悪化に備えられるか」を確認する別の判断です。

| 用語 | 意味 | 観察 |
|---|---|---|
| readiness | SBTを試せる準備状態 | 原因改善、oxygenation、循環、覚醒、呼吸努力 |
| SBT | 少ないsupportでの自発呼吸試験 | 呼吸数、VT、努力、SpO₂、心拍、血圧、苦痛 |
| extubation readiness | tubeを安全に抜ける準備 | 意識、cough、分泌物、上気道、誤嚥、再挿管risk |

**新人看護師の到達点：** 鎮静、覚醒、呼吸努力、分泌物、cough、循環を観察し、SBT前後の変化と中止徴候を報告できること。

**ベテラン向け深掘り：** SBT failureの心・肺・神経筋・代謝要因、extubation failure risk、予防的post-extubation support、再挿管遅延を評価します。

### 報告例

> 「SBT開始○分です。呼吸数、VT、SpO₂、心拍、血圧、努力・発汗・苦痛は○○です。開始前から○○へ変化し、cough、分泌物、意識、上気道riskは○○です。」

## 1. Overview

Liberationは原因回復の評価、鎮静最小化、早期離床、毎日のreadiness screening、SBT、extubation readiness、抜管後supportを含むprocessです。遅すぎる離脱と早すぎる抜管の双方に害があります。

## 2. Readiness and SBT

- 原因が改善傾向、oxygenation/ventilationが許容、循環が概ね安定
- spontaneous effort、意識/comfort、代謝負荷、分泌管理を評価
- SBT中はRR/VT等の単一indexより、呼吸pattern、WOB、gas exchange、循環、意識、苦痛の全体とtrendを見る
- failureなら「失敗」のlabelで終わらず、cardiac load、fluid、diaphragm/neuromuscular、airway resistance、infection、anxiety/delirium、nutrition等を探索

ATS/CHEST 2017は、初回SBTで少量のinspiratory pressure augmentationを用いること、protocolized sedation minimization、high-risk患者でextubation直後のpreventive NIV等をconditionalに推奨しています。対象選択が必要です。

## 3. Extubation Readiness

SBTに加え、airway patency、cough strength、secretions量/吸引頻度、意識と指示理解、aspiration risk、再挿管難易度、post-extubation supportを評価します。cuff leak testは上気道浮腫リスクが高い患者に選択的に用い、単独で抜管可否を決めません。

## 4. Clinical Reasoning

```text
毎日readiness → SBT → toleranceならairway/secretions/coughを別評価
→ failure riskと再挿管難易度 → 抜管後HFNC/NIV計画
→ 抜管 → voice/stridor/WOB/gas/secretionsを早期再評価
→ failureなら非侵襲supportに固執せず再挿管を判断
```

## 5. Nursing Points

- SAT/SBT前に鎮静、疼痛、睡眠、delirium、体位、分泌、予定処置を共有
- trial条件、開始/終了時刻、vital、WOB、患者の訴え、failure理由を再現可能に記録
- extubation前にsuction、oxygen/support、emergency airway、communication planを準備
- 抜管後はstridor、voice、嚥下、cough、分泌、疲弊、夜間悪化を監視
- mobilization、口腔ケア、栄養、家族参加で全身回復を支える

## 6. Red Flags / Pitfalls

- stridor、silent/weak cough、進行するWOB、意識低下、hypercapnia/acidosis、循環不安定
- SBTを毎日検討しない、RSBIだけで決定、SBT failure原因未分析、抜管後NIVで再挿管を遅延

## 7. Take Home Messages

1. Liberationは毎日の多職種processである。
2. SBTは呼吸能力、extubationはairway安全性も問う。
3. failure理由を病態に分解し、抜管後supportとrescue planを先に決める。
