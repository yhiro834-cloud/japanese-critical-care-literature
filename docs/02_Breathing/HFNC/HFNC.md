# 高流量鼻カニュラ酸素療法

> [!CAUTION]
> HFNC trialは挿管適応を消しません。意識障害、airway protection不良、循環不安定、疲弊、進行性acidosisでは直ちに上位supportを検討します。

## 0. まず覚える

**高流量鼻カニュラ酸素療法（high-flow nasal cannula：HFNC）**は、加温・加湿した高流量gasを鼻カニュラから投与する呼吸supportです。

**簡単に言うと：** 通常の鼻カニュラより安定した酸素供給と高いflowで患者の吸気需要を支えますが、人工呼吸器の代わりになるとは限りません。

| 用語 | 意味 | 観察 |
|---|---|---|
| flow | 1分間に流すgas量 | 患者の吸気需要、comfort、口呼吸、leak |
| FiO₂ | 吸入酸素濃度 | SpO₂だけでなく必要量のtrendを見る |
| ROX index | SpO₂/FiO₂と呼吸数から算出する指標 | 単独cutoffで挿管可否を決めない |

**新人看護師の到達点：** flowとFiO₂を区別し、呼吸数、努力、意識、循環、装着、加温加湿、皮膚を経時的に評価すること。

**ベテラン向け深掘り：** 数字が保たれていても努力・疲弊・acidosisが進むfailureを見抜き、trial開始時に再評価時刻とescalation条件を共有します。

### 報告例

> 「HFNCはflow○、FiO₂○です。SpO₂は○ですが、呼吸数は○から○へ、努力と会話、意識、血圧は○○です。開始○分後で改善/不変/悪化しています。」

## 1. Overview / Physiology

HFNCは加温加湿した高流量gasを供給し、患者の吸気需要への追従、FiO₂安定化、上気道dead-space washout、少量で変動するpositive pressure、comfort改善を期待します。効果は口の開閉・flow・解剖・呼吸patternで変わります。

## 2. Assessment and Clinical Reasoning

開始前に原因、oxygenation、RR/WOB、意識、循環、PaCO₂/pHリスク、goals of careを確認します。開始後は「SpO₂が上がったか」だけでなく、RR、accessory muscle、呼吸困難、意識、循環、FiO₂/flow需要のtrendを短い間隔で評価します。

```text
適応候補 → failure riskと挿管計画を共有 → fit/温度/flow/FiO₂を個別調整
→ 早期再評価 → WOB・oxygenation・循環が改善なら継続
→ 横ばい/悪化なら原因再評価とNIV/挿管へのescalation
```

ROX index（`SpO₂/FiO₂ ÷ RR`）はtrendの補助であり、単一cutoffや単独判断で挿管を遅らせません。対象集団・時点で性能が異なります。

## 3. Indications and Boundaries

ERS 2022は成人hypoxemic acute respiratory failureでHFNCをconventional oxygenより提案しましたが、多くはconditional recommendationです。COPDを伴うhypercapnic ARFではNIV trialをHFNCより先に行う提案です。cardiogenic pulmonary edemaやCOPD exacerbationでは[NIV](../NIV/NIV.md)のevidenceを優先して評価します。

## 4. Nursing / Troubleshooting

- cannula size/位置、口腔・鼻腔、皮膚、温度、加湿水、回路結露、電源・酸素供給を確認
- 食事、会話、移動時のdesaturationとsupport中断時間を記録
- alarmが少ないことを安全と誤認せず、連続monitorとbedside assessmentを行う
- 急変時は患者→cannula/回路→device→gas sourceの順に確認し、代替酸素と挿管準備を並行

## 5. Red Flags / Pitfalls

- RR/WOB上昇、thoracoabdominal asynchrony、意識低下、shock、pH低下
- FiO₂増加を繰り返すだけ、ROXだけで安心、長い無評価trial、患者移送時の供給不足

## 6. Take Home Messages

1. HFNCはcomfortと酸素化だけでなくWOBのtrendで評価する。
2. failure予測指標は臨床判断を補助するだけである。
3. 開始時に再評価時刻とescalation planを決める。
