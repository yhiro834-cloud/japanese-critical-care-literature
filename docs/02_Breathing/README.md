# 02 Breathing

Bでは、酸素化、換気、呼吸仕事量を分け、患者・device・循環・経時変化を統合します。

## 新人看護師の読み順

1. [呼吸生理](Respiratory_Physiology/RESPIRATORY_PHYSIOLOGY.md)：oxygenation、ventilation、V/Q、shunt、dead space
2. [酸素療法](Oxygen_Therapy/OXYGEN_THERAPY.md)：device、flow/FiO₂、観察、再評価
3. [HFNC](HFNC/HFNC.md) / [NIV](NIV/NIV.md)：適応、装着、failure、escalation
4. [動脈血液ガス](ABG/ABG_INTERPRETATION.md)：pH、PaCO₂、HCO₃⁻、PaO₂
5. [人工呼吸器の基本用語](Mechanical_Ventilation/VENTILATOR_TERMS.md) → [人工呼吸管理](Mechanical_Ventilation/MECHANICAL_VENTILATION.md)
6. [ARDS](ARDS/ARDS.md) / [人工呼吸器離脱](Weaning/VENTILATOR_LIBERATION.md)

## ベテラン看護師の学習焦点

- SpO₂だけでなく酸素含量・酸素運搬・換気・死腔・循環を統合する。
- support開始時に目的、再評価時刻、成功/失敗条件、次の手段を共有する。
- 肺保護だけでなく横隔膜、患者努力、右心、鎮静、せん妄、mobilizationを統合する。
- SBT、抜管、抜管後support、再挿管計画を別々に評価する。

呼吸生理、ABG、酸素療法、HFNC、NIV、人工呼吸器、ARDS、weaning、VV-ECMOを扱います。
