# Oxygen Therapy

> [!CAUTION]
> 酸素は薬剤です。低酸素血症の原因治療、換気評価、投与後の再評価を伴わない「SpO₂だけの補正」は危険です。目標範囲とdevice escalationは施設手順・患者背景で個別化してください。

## 1. Overview

酸素療法の目的は、組織酸素供給を保ちながらhypoxemiaと過剰酸素曝露の害を避けることです。PaO₂/SpO₂は酸素化を示しますが、DO₂は心拍出量・Hb・SaO₂で決まります。

## 2. Why It Matters

低SpO₂にはV/Q mismatch、shunt、hypoventilation、diffusion、低吸入酸素、測定誤差があります。酸素への反応だけで病態を確定できません。

## 3. Physiology / Pathophysiology

`CaO₂ ≈ 1.34 × Hb × SaO₂ + 0.003 × PaO₂`。溶解酸素よりHb結合酸素が主体です。COPD等でhypercapnic respiratory failureのリスクがある患者では、酸素投与後のPaCO₂/pH悪化を臨床所見と血液ガスで監視します。

## 4. Assessment and Monitoring

- ABCDE、意識、呼吸数、努力呼吸、発語、胸郭運動、聴診、循環
- device、flow/FiO₂、装着状態、SpO₂波形と灌流、Hb、ABG/VBGの問い
- 必要酸素量のtrendと原因治療への反応
- dyshemoglobin、低灌流、体動、色素、皮膚色などpulse oximetryの限界

## 5. Clinical Reasoning

```text
低SpO₂/呼吸苦 → まず患者と波形を確認 → airway/ventilation/perfusionを同時評価
→ device・供給源・接続を確認 → 原因仮説 → 適切なsupport
→ 数分単位で意識・WOB・SpO₂・必要ならgasを再評価 → 改善しなければ早期escalation
```

## 6. Device Selection

低流量nasal cannula、simple/controlled mask、reservoir maskは、必要FiO₂、患者の吸気流量、CO₂ retention risk、緊急度に応じて選びます。実際のFiO₂は呼吸pattern、leak、fitで変動します。高い吸気需要や持続するhypoxemiaでは[HFNC](../HFNC/HFNC.md)、[NIV](../NIV/NIV.md)、侵襲的換気を検討します。

## 7. Nursing Points / Troubleshooting

- 処方目標、device、flow/FiO₂、皮膚・粘膜、加湿、水分貯留、火気を確認
- 突然の低下は患者側（airway、pneumothorax、secretions、perfusion）、回路側、機器/電源/供給側に分ける
- escalationをdevice名だけで判断せず、意識・WOB・gas・循環を併記して報告

## 8. Red Flags / Pitfalls

- 酸素増量にもかかわらず悪化、silent chest、疲弊、意識低下、循環不安定
- 良好なSpO₂だけでventilation failureや低DO₂を除外
- sensor値を患者より優先、酸素開始後の再評価なし、NIV/挿管の遅延

## 9. Take Home Messages

1. 酸素は原因治療ではなくsupportである。
2. SpO₂は患者・波形・Hb・灌流・PaCO₂と統合する。
3. 必要量の増加とWOB悪化は早期escalationの合図である。
