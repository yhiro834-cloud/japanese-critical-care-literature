# 05 Renal

腎領域では、creatinine・尿量だけでなく、循環、静脈うっ血、閉塞、薬剤、体液、電解質、時間経過を統合します。

AKI、CRRTなどの略語は、[学習案内の用語表](../FIRST_THIRD_STUDY_GUIDE.md#略語の読み方)で正式名称と治療上の限界を確認してください。
