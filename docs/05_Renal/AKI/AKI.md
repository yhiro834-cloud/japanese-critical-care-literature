# Acute Kidney Injury

> [!CAUTION]
> KDIGO 2026 AKI/AKDは2026-08-11時点でpublic-review draftであり、最終版ではありません。本頁の診断stageは現行最終版KDIGO 2012を使用し、草案の新規推奨を確定事項として採用しません。

## 0. まず覚える

**急性腎障害（acute kidney injury：AKI）**は、短期間に腎機能が低下するsyndromeで、血清creatinine上昇または尿量低下で定義・stage分類します。

**簡単に言うと：** creatinineだけでなく尿量、循環、うっ血、閉塞、薬剤、時間経過を一緒に見ます。

| 用語 | 意味 | 限界 |
|---|---|---|
| SCr | 血清creatinine | 変化が遅く筋量・希釈の影響を受ける |
| oliguria | 尿量低下 | catheter閉塞、体格、diuretic等も影響 |
| nephrotoxin | 腎障害を起こし得る薬剤・物質 | 適応、dose、濃度、併用、回避可能性を確認 |
| congestion | 静脈うっ血 | 腎灌流は動脈側だけでなく静脈側にも影響される |

**新人看護師の到達点：** 時間尿、catheter、fluid balance、体重、血圧、浮腫、薬剤、検査trendを確認し、急な乏尿を報告すること。

**ベテラン向け深掘り：** creatinine dilution、baseline不明、AKD、demand–capacity、venous congestion、腹腔内圧、薬物動態、回復後riskを統合します。

## 1. Overview

AKIはserum creatinine上昇または尿量低下で定義されるsyndromeで、原因、trajectory、fluid balance、drug exposure、回復後riskを評価します。creatinineは遅行性で、筋量・希釈・産生に影響されます。尿量は早期signalですが閉塞、diuretic、catheterにも影響されます。

## 2. KDIGO 2012 Definition and Staging

AKIは次のいずれか：SCrが48時間以内に≥0.3 mg/dL上昇、7日以内にbaselineの≥1.5倍、または尿量<0.5 mL/kg/hが6時間。stageはSCrと尿量の**重い方**で判定します。baseline不明、fluid dilution、RRT開始時は限界を明記します。

## 3. Etiologic Framework

- hemodynamic/perfusion：shock、低CO、過度のvasodilation/vasoconstriction
- congestion：RV/heart failure、abdominal pressure、venous outflow
- intrinsic：sepsis-associated、ATN、AIN、GN、TMA、pigment
- obstruction：catheter、ureter/膀胱、腹腔/骨盤病態
- drug/toxin/contrast exposure

“pre-renal/renal/post-renal”だけで止めず、複数mechanismとtime courseを考えます。

## 4. Assessment

- baseline SCr/eGFR、尿量時系列、urinalysis/sediment、protein/blood
- hemodynamics、fluid need/tolerance、congestion、bladder scan/renal imaging
- medication reconciliation：dose adjustment、nephrotoxin combination、levels
- CK、hemolysis、infection、autoimmune/TMA等を文脈で追加
- mass balance：体重、fluid input/output、Na/K/acid–base、nutrition

## 5. Prevention and Management

原因治療、perfusion最適化、不要nephrotoxin回避/調整、適切なfluid、glycemic/electrolyte管理、obstruction解除を行います。“renal-dose dopamine”や単に尿量を増やす介入を腎回復と同一視しません。contrastが必要なtime-critical診断/治療をAKI fearだけで遅らせず、risk–benefitと予防を検討します。

## 6. Clinical Reasoning

```text
SCr↑/尿量↓ → 本物か・baseline/時間 → stageと緊急合併症
→ perfusion / congestion / intrinsic / obstruction / drug
→ urine・sediment・POCUS/imaging・labs → 原因介入
→ K/acid/base/volume/uremiaとtrajectory → KRT適応
→ 回復・drug再調整・退院後follow-up
```

## 7. Nursing Points

- hourly urineはcatheter kink/position/bladder、flush/order、body weightを確認
- oliguriaを即“脱水”とせず、呼吸/edema/JVP/POCUS/hemodynamicsを共有
- fluid、antibiotic、contrast、NSAID等の時刻とrenal trendを紐づける
- daily weight、cumulative balance、K/Mg/Phos/Na/HCO₃、nutritionを監視
- AKI回復時はdrug clearance増加とpost-AKI follow-upの必要性をhandoff

## 8. Red Flags / Pitfalls

- refractory hyperkalemia/acidosis/pulmonary edema、uremic complication、anuria、急速なstage進行
- SCr正常でAKIなし、尿量低下へblind fluid、eGFR自動値で急性drug doseを決定
- AKI改善後にnephrotoxic/dose-adjusted薬を戻さない・追跡しない

## 9. Take Home Messages

1. SCrと尿量の両方をtrajectoryで評価する。
2. perfusion不足とcongestionを同時に考える。
3. AKIは退院後CKD riskまで続くcare pathwayである。
