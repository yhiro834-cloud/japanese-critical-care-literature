# 気管チューブ・気管切開の管理

![気道・肺・気管チューブ・人工呼吸器回路の教育用イラスト](../../../assets/illustrations/airway_ventilator_anatomy_v1.png)

> [!NOTE]
> 解剖と機器の位置関係をつかむための教育用イラストです。実際のチューブ位置は呼気二酸化炭素波形、左右換気、深さ、画像などで確認し、図だけで判断しません。

> [!NOTE]
> **図で確認：** [気管切開の解剖と急変時安全確認](../../../assets/airway/tracheostomy_safety_anatomy.svg) — 上気道との交通、瘻孔の成熟度、カニューレ・肺・機器を分けて確認する。

> [!CAUTION]
> 人工気道患者の突然の悪化ではdisplacement、obstruction、pneumothorax、equipment failureを即時評価します。気管切開の成熟度や術式により再挿入の危険性が異なるため、施設emergency algorithmを優先してください。

## この章の使い方

- **新人看護師：** tubeの位置、固定、開通性、cuff、分泌物、加湿、皮膚を同じ順序で確認します。
- **中堅・ベテラン：** 急変時のDOPE、気管切開の成熟度、再挿入risk、抜管計画、bundle実装を深めます。

## 1. まず覚える

**人工気道**は、気管チューブまたは気管切開tubeを通して気道を確保する方法です。

**簡単に言うと：** tubeは空気の通り道を作りますが、位置ずれ、閉塞、leak、皮膚・粘膜障害を起こし得るため、入っているだけでは安全ではありません。

| 用語 | 意味 | 看護でのポイント |
|---|---|---|
| ETT | 気管チューブ（endotracheal tube） | 深さ、固定、口腔、cuff、ETCO₂を確認 |
| tracheostomy | 気管切開 | 術式、作成日、成熟度、上気道との交通、予備tubeを確認 |
| cuff | tube周囲を密閉するballoon | leakと誤嚥risk、粘膜圧迫の両方を考える |
| humidification | 加湿 | 上気道を迂回するため、分泌物乾燥と閉塞予防に重要 |
| suction | 吸引 | 分泌物を除去する処置。routineではなく適応と反応を確認 |
| VAP | 人工呼吸器関連肺炎 | 単一処置でなく、口腔・体位・鎮静・離脱等をbundleで扱う |
| DOPE | displacement、obstruction、pneumothorax、equipment failure | 挿管患者急変の原因整理。患者評価と並行して使う |

## 2. 新人看護師の到達目標

1. shift、体位変換、搬送の前後でtube深さ・固定・ETCO₂・左右換気を確認できる。
2. 吸引の適応、実施前後のSpO₂・循環・患者反応・分泌物を説明できる。
3. suction catheterが通らない、ETCO₂消失、急なleak、皮下気腫を緊急報告できる。
4. tubeだけでなく口腔、皮膚、communication、comfort、離脱計画まで観察できる。

## 3. Overview

人工気道管理は位置・開通性・cuff seal・固定・粘膜/皮膚・分泌・加湿・communication・離脱計画を一体で扱います。tubeがあること自体が安全を保証しません。

## 4. Assessment and Monitoring

- ETT/tracheostomy type、size、depth、固定、挿入日、経路、spare tube
- continuous waveform ETCO₂、exhaled VT、pressure/flow、breath sounds、secretions
- cuff pressureは施設基準と機器で測定し、leak/aspiration riskと粘膜障害を両面評価
- stoma、口唇/口腔、皮膚、出血、皮下気腫、感染、嚥下/発声

### 毎回同じ順番で確認する

| 順番 | 見るもの | 異常時の考え方 |
|---|---|---|
| 1 患者 | 意識、胸郭、呼吸努力、SpO₂、循環 | tube以外の病態も同時に考える |
| 2 位置 | 深さ、固定、ETCO₂、左右換気 | displacement、片肺挿管、抜去 |
| 3 開通性 | 分泌音、pressure/flow、catheter通過 | 分泌物、屈曲、bite、血餅 |
| 4 seal | cuff、leak、呼気VT、発声 | cuff、tube位置、回路、気道損傷 |
| 5 組織 | 口唇、口腔、stoma、皮膚、出血 | 圧迫、感染、壊死、瘻孔、出血 |

## 5. Suction and Humidification

suctionは分泌音、sawtooth waveform、pressure上昇、換気低下、可視分泌等の適応で行い、深さ・時間・陰圧は施設手順に従います。実施前後にoxygenation、HR/BP、patient tolerance、分泌を評価します。加湿不良は粘稠分泌と閉塞を促進し、過剰な結露は回路問題となります。

## 6. VAP Prevention and Daily Care

- head/positionを患者状態に合わせ、口腔ケア、hand hygiene、回路の清潔操作を実施
- sedation minimization、早期mobilization、毎日のliberation readinessを多職種で確認
- ventilator circuitをroutineに不要交換せず、汚染/故障時は施設感染対策に従う
- aspiration、subglottic secretion management等は患者・tube・local bundleに合わせる

VAP bundleは単一項目ではなく、各介入の適応と害を含めて実装します。

## 7. Extubation / Decannulation Interface

[Ventilator Liberation](../../02_Breathing/Weaning/VENTILATOR_LIBERATION.md)を呼吸離脱のSSOTとします。抜管前はdifficult reintubation、上気道浮腫、cough/secretions、aspiration、post-extubation supportを確認します。DAS extubation guidelineはextubationをelective processとして計画し、at-risk airwayのreintubation strategyを重視します。

## 8. Emergency Troubleshooting

```text
急変 → patient/oxygenation → tube position/patency → circuit → ventilator → chest pathology
→ 必要なら回路を外しbagで抵抗・胸郭を評価
→ ETT: capnographyとdepth、suction catheter通過を確認
→ tracheostomy: emergency algorithm、口/鼻からのoxygenation可否、stoma maturityを確認
```

## 9. Nursing Practice

- shift・体位変換・搬送の前後でdepth、固定、skin、cuff、ETCO₂をdouble-check
- suction catheterが通らない、急なleak/voice、ETCO₂消失は緊急所見
- tracheostomy bedsideに同サイズと1サイズ小さいtube、obturator、suction、bag-maskを施設基準で準備
- communication aid、口腔ケア、睡眠、家族参加、尊厳をsupportする

### 報告例

> 「体位変換後にETCO₂波形が消失し、呼気VTが低下しました。tube深さは前回○cmから○cm、固定は○○、左右胸郭運動は○○、SpO₂と血圧は○○です。回路接続を確認し、応援と換気準備を開始しています。」

**介入後の再評価：** tube位置、ETCO₂、胸郭、左右呼吸音、pressure/flow、呼気VT、SpO₂、循環、皮膚・固定を確認し、再発防止策をhandoverします。

## 10. ベテラン看護師向け深掘り

気管切開の脱落対応は、作成時期、術式、stoma成熟度、上気道から換気できるかで異なります。盲目的再挿入はfalse passageを作る危険があります。bedside informationにtube種類・size・作成日・上気道の状態・緊急algorithmを明示し、必要器材と役割をshiftごとに確認します。

## 11. Red Flags / Pitfalls

- ETCO₂消失、suction不能、急なhigh pressure、massive air leak、出血、皮下気腫
- cuffをleakのたび盲目的に増圧、routine suction、固定部の観察不足
- newly formed tracheostomyを盲目的に再挿入、抜管をSBTだけで決定

## 12. 確認問題

1. cuff leakを認めたとき、圧を追加する前に何を確認しますか。
2. suction catheterが通らない場合に疑うことは何ですか。
3. 気管切開tube脱落時、作成日と術式が重要なのはなぜですか。

## 13. Take Home Messages

1. 人工気道は位置・開通・seal・皮膚・分泌を反復評価する。
2. 急変はtube、circuit、equipment、patient pathologyに分ける。
3. 抜管/decannulationと再確保計画を同時に考える。
