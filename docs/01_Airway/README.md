# 01 Airway

気道（airway）は、空気が鼻・口から肺へ出入りする通り道です。Aでは、いま開通しているか、維持できるか、悪化時に酸素化を救えるかを評価します。

略語は暗記せず、[学習案内の用語表](../FIRST_THIRD_STUDY_GUIDE.md#略語の読み方)で正式名称と臨床的な意味を確認してください。

## ベテラン看護師の学習焦点

- 解剖学的困難だけでなく、生理学的困難と無呼吸への耐容性を評価する。
- attemptを増やす害と、mask・SGA・FONAへの移行条件をteamで共有する。
- 気管切開の術式・成熟度・上気道の状態を含めて脱落時algorithmを準備する。
- 一時的な改善を終了点とせず、原因、反応、再発防止まで評価する。

## 基本用語

- **ETCO₂：** 呼気終末二酸化炭素。持続する波形は気管tube位置と換気評価の中心です。
- **ETT：** 気管チューブ。
- **SGA：** 声門上器具。mask換気や挿管困難時の救済に用います。
- **FONA：** 前頸部からの緊急気道確保。
- **cuff：** tube周囲を密閉するballoon。過不足の両方に害があります。
- **DOPE：** displacement、obstruction、pneumothorax、equipment failureの整理法です。
