# Case: Escalating Respiratory Support

## Presentation

肺炎疑いの患者。reservoir mask下でもSpO₂ 89%、RR 34/min、努力呼吸。血圧は保たれ会話可能だが疲労感が増えている。

## Pause 1: 最初の5分

**問い:** 数値を上げる前に何を確認するか。

**Reasoning:** ABCDE、波形、device/供給、airway、胸郭/聴診、循環、意識を同時評価し、ABG、画像、培養等を原因治療へつなげる。HFNC候補でも、挿管困難性とfailure時の計画を先に共有する。

## Evolution

HFNC開始後、SpO₂ 94%だが1時間でRR 38/min、会話困難、thoracoabdominal asynchronyが出現。FiO₂需要も増加。

## Pause 2: 「SpO₂改善」をどう解釈するか

oxygenationの一部は改善しても、WOBと疲弊は悪化している。HFNC failureを疑い、原因再評価と挿管準備を並行する。単一indexや追加観察だけでescalationを遅らせない。

## Evolution

挿管後P/F 95、両側陰影、心原性だけでは説明困難。肺保護換気を開始したがhypoxemiaが持続。

## Pause 3: 次の統合

ARDS定義・alternative、Pplat/total PEEP/PBW、hemodynamics/RV、prone適応、原因治療を確認する。介入後はP/Fだけでなくpressure、循環、tube/line、皮膚を再評価する。

## Nursing Debrief

- device変更前後の時刻、FiO₂/flow、RR/WOB、意識、循環を揃えて記録
- 「SpO₂は改善、努力呼吸は悪化」と矛盾を明確にhandoff
- 挿管・prone時のairway、line、skin、emergency planをchecklist化
