# Case: Occult Hemorrhage after Trauma

交通外傷。到着時BP 118/72、HR 104、皮膚冷感。eFAST陰性で左大腿部痛がある。初期Hbは正常域。

## Pause 1

正常血圧・初期Hb・eFAST陰性はmajor hemorrhageを除外しない。保温しながら`<C>ABCDE`を反復し、胸腔、後腹膜/骨盤、長管骨、体外の出血源とperfusion trendを再評価する。

## Evolution

骨盤部痛が増し、BP 92/58、意識が鈍化。再診察で骨盤輪損傷が疑われる。

## Pause 2

MTP/trauma surgery/IRを起動し、適切なbinder、採血・血液準備、warming、calcium/coagulation monitoringを並行する。CTへ行けるかは「撮りたいか」でなく、蘇生反応とdefinitive controlへの最短経路で決める。

## Debrief

- 単発の陰性所見でmechanism-consistent injuryを閉じない。
- 一過性反応は出血制御ではない。
- 時刻付きtrendと介入反応をhandoverする。
