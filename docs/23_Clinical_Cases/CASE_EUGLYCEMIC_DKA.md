# Case: Euglycemic DKA

糖尿病、SGLT2 inhibitor使用。嘔吐、頻呼吸、glucose 176 mg/dL、anion-gap metabolic acidosis。

## Pause 1

glucoseが高度でないことだけでDKAを除外しない。β-hydroxybutyrate、pH/bicarbonate、electrolytes、renal function、lactate/toxin等の鑑別、薬剤/絶食/感染/insulin interruptionを確認する。

## Evolution

ketosisを確認。Kは低下傾向、脱水と感染triggerが疑われる。

## Pause 2

fluid、K安全、protocolized insulinと必要なdextrose、感染評価を並行し、glucoseではなくketosis/acidosis resolutionを追う。退院前にSGLT2 sick-day/peri-procedure planを見直す。
