# Case: False Alarm or True Deterioration?

夜勤中、SpO₂ 82% alarm。pleth不良で患者は会話可能だが、同時に頻呼吸と冷汗。

## Pause 1

artifactと決めず患者をABCDE評価し、pulse/別site/ABG等で信号を照合。oxygen source、airway/circuit、lung/circulationを並行確認する。

## Evolution

SpO₂ probe交換で96%だが、BP低下と新規胸痛を確認。

## Pause 2

一つのfalse signalが全症状を説明しない。急性循環イベントとしてECG/POCUS等を起動し、timelineとresponseをhandoverする。
