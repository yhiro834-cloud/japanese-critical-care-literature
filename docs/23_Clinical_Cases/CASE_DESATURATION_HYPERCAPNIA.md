# Case: SpO₂突然低下とPaCO₂上昇

## Learning Objectives

- SpO₂ alarmを患者・airway・device・breathingへ分解する
- oxygenation failureとventilation failureを区別する
- ABGを採血条件とclinical trendから解釈する

## Case Stem

68歳、肺炎でhigh-flow oxygen therapy中。体位変換後にSpO₂ 95%から84%、RR 32/min。数分後、呼吸数は18/minへ低下したが努力呼吸と傾眠が出現。直前ABGはなく、現在のFiO₂は記録で確認中。

## Problem Representation

肺炎患者の体位変換後に急性desaturation。RR低下は改善ではなく疲弊・ventilatory failureの可能性がある。

## Immediate Assessment — ABCDE

### A — Airway

発声、stridor、分泌物、舌根沈下、aspiration。吸引とairway supportを準備し応援要請。

### B — Breathing

- 胸郭左右差、呼吸音、effort、paradoxical movement
- oxygen source、device接続、flow、cannula位置
- SpO₂ plethとpulse一致
- ETCO₂があればwaveformを確認

### C — Circulation

Pulse、BP、CRT、arrhythmia。低CO/低灌流はSpO₂ signalとgas exchangeを悪化させ得る。

### D — Disability

意識、pupil、血糖。Hypercapnia、hypoxemia、薬剤を鑑別。

### E — Exposure

発熱、rash、胸部外傷、sedative/opioid投与、体位・line/device変化。

## Differential Diagnosis

| Category | Candidate |
|---|---|
| Airway | secretion plug、aspiration、upper airway obstruction |
| Lung | atelectasis、pneumonia progression、pneumothorax、edema |
| Vascular/circulation | PE、low CO |
| Ventilation | fatigue、CNS depression、neuromuscular weakness |
| Device/measurement | oxygen disconnection、flow error、sensor artifact |

## Additional Assessment

ABGを採取する場合はFiO₂、device、体位、時刻を記録。Portable imaging/POCUS、ECG、laboratoryを原因仮説に応じ追加。

ABG: `pH 7.24 / PaCO₂ 68 / HCO₃ 28 / PaO₂ 58`（FiO₂ 0.60と確認）。

## Interpretation

Acidemia + PaCO₂上昇でprimary respiratory acidosis。HCO₃上昇は小さく、急性成分を示唆するがbaseline不明。P/Fは約97だが、設定・PEEP・time pointを含めて解釈。低酸素と換気不全が併存し、傾眠・疲弊はred flag。

## Initial Intervention

Airway/ventilatory supportを緊急にteamで判断し、分泌物・device・肺病変等の原因へ対応する。酸素増量だけでPaCO₂上昇と疲弊を治療したことにはなりません。

## Reassessment

意識、work、SpO₂/signal、ETCO₂、ABG trend、hemodynamics、介入の害を同じ条件で再評価します。

## Debrief / Clinical Reasoning

RRが32から18へ低下したことを「改善」と解釈しない点が核心です。呼吸pattern、depth、意識、PaCO₂を統合すると、fatigueによるalveolar ventilation低下が疑われます。

## Nursing Actions and Escalation

- 急変時刻、体位、device/FiO₂、SpO₂ waveform、RR pattern、意識を報告
- airway equipment、suction、ventilation backupを準備
- ABG label/source/条件を確認しcritical resultをread-back
- intervention後の比較値を記録

## Common Pitfalls

- RR低下を改善と判断
- oxygen増量のみで終了
- SpO₂ sensor errorと決めつける
- ABGのFiO₂/体位を記録しない

## Questions

1. Oxygenation failureとventilation failureを示す所見はそれぞれ何か。
2. このABGのprimary disorderは何か。
3. 最初に除外すべきreversible device problemは何か。

## Answer and Explanation

1. PaO₂/SpO₂低下がoxygenation、PaCO₂上昇・傾眠・疲弊がventilation failureを示す。
2. Acute componentの強いrespiratory acidosis。
3. Oxygen source、flow、接続、cannula位置、sensor signal。確認中も患者へのsupportを遅らせない。
