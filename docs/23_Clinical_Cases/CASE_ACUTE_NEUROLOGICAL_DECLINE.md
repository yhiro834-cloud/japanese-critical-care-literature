# Case: Acute Neurological Decline

SAH治療中の患者。1時間前は命令に従っていたが、現在開眼せず右瞳孔が拡大。鎮静薬は変更なし。

## Pause 1

monitor確認だけでなくABCDE、glucose、pupil/GCS component、airway/PaCO₂/O₂、MAP/ICP/EVD level、seizure、Na/temperatureを同時評価し、herniation emergencyと再出血/hydrocephalus/DCIを含む原因検索を開始する。

## Evolution

EVD transducerが体位変換後に基準点より高く、drainageが停止。修正後も意識は戻らず、顔面の微細な反復運動がある。

## Pause 2

level errorを修正しただけで終了せず、NCSEを疑いEEGと治療を進め、緊急画像/専門家評価を継続する。複数原因が併存し得る。

## Debrief

- score合計よりcomponent/左右差/trend。
- device artifactと真の悪化を二者択一にしない。
- herniation bridgeとdefinitive cause controlを並行する。
