# Case: Acute Platelet Fall in ICU

sepsis改善中、plateletが3日で65%低下。heparin prophylaxis中、line-associated thrombosis疑い。

## Pause 1

DICと断定せず、pseudothrombocytopenia、HIT timing/degree/thrombosis、TMA、drug/device、liver/dilutionを比較する。smear、coagulation/hemolysis、4Ts等のpretest assessmentを行う。

## Evolution

4Ts中高probability。新規DVTを確認。

## Pause 2

全heparin exposureを止め、検査を提出し、bleeding/renal/hepatic functionに合わせたnon-heparin anticoagulationを専門protocolで開始する。platelet輸血をcountだけでroutine化しない。
