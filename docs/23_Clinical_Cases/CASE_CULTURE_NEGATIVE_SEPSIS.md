# Case: Culture-negative Sepsis Reassessment

shockと肺浸潤影でbroad empiric therapy開始。48時間後、血液/喀痰培養陰性、pressorは減量したが発熱継続。

## Pause 1

“培養陰性＝感染なし”でも“発熱＝broadening”でもない。検体品質/抗菌薬前採取、肺以外のsource、画像、device、薬剤熱/PE/膵炎等のmimic、source control、clinical trajectoryを再評価する。

## Evolution

腹部再診察で右上腹部圧痛、画像で胆道閉塞を確認。

## Pause 2

抗菌薬拡大のみでなく緊急source controlを調整し、procedure sampleを採取。臓器機能/CRRT、local susceptibilityに合わせdoseを見直し、結果後にnarrowとduration/end dateを決める。

## Debrief

- diagnostic timeoutは“抗菌薬を続ける確認”ではなく診断を作り直す時間。
- source control遅延を薬剤追加で代替しない。
- culture negativeでもde-escalation/中止を検討できる。
