# Case: Agitation, Weakness, and Recovery

sepsis後、挿管中。夜間agitation、日中傾眠、四肢筋力低下。家族は不安で面会を避けている。

## Pause 1

鎮静増量前にpain、hypoxia、retention、withdrawal、device、sleep、deliriumを評価。daily sedation goal、SAT/SBT、昼夜cue、family inputを連携する。

## Evolution

覚醒後も立位困難、悪夢と記憶混乱。

## Pause 2

mobility/swallow/cognition/moodをscreenし、退院summary、rehab、PICS/PICS-F follow-up、家族支援を具体的なowner/date付きで調整する。
