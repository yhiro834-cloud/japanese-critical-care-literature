# Case: Line Break and Occupational Exposure

central line connectionが外れ血液が飛散。患者はvasopressor中、staff眼粘膜へ曝露。

## Pause 1

患者を先にstabilizeし、lineをaseptically secure/replaceする。staffは直ちに眼洗浄し、occupational exposure pathwayを起動する。incidentを隠さずsource/PEP時刻を記録する。

## Pause 2

患者側のair embolism、blood loss、contamination、drug interruptionを再評価。connector/line tension、PPE、role、transport setupをsystem debriefする。
