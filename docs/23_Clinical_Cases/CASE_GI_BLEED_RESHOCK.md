# Case: Recurrent Shock in GI Bleeding

melenaで入院。初期Hbは比較的保たれたが、冷感・頻脈。cirrhosis歴あり。

## Pause 1

初期Hbで出血量を過小評価せず、ABCDE、access/crossmatch、serial perfusion/Hb、抗血栓薬を確認する。variceal pathwayを早期起動し、airway riskとendoscopy準備を並行する。

## Evolution

一度安定後に鮮血便、低血圧、意識低下。

## Pause 2

再出血としてresuscitationを再開し、repeat endoscopy/IR/surgeryの最短経路をactivateする。hematocheziaでもupper sourceを閉じない。
