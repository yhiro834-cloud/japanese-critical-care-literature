# Toxicology Initial Approach

## 0. まず覚える

急性中毒では、物質同定を待つ前に現場・医療者の安全を確保し、ABCDE、glucose、深部体温、ECGを評価する。**supportive careを始めながら、曝露情報とtoxidromeから仮説を作り、中毒専門家へ早期相談する。**

**簡単に言うと：** antidote探しから始めず、まず呼吸・循環・痙攣・不整脈・体温を支え、何をどの経路でいつ曝露したかを整理する。

| 用語 | 意味 | 実践上のポイント |
|---|---|---|
| toxidrome | 中毒物質群に特徴的な症候の組合せ | 診断確定ではなく、混合摂取・mimicを常に考える |
| supportive care | airway、換気、循環、痙攣等を支える治療 | 多くの中毒で転帰を左右する中心治療 |
| decontamination | 皮膚・眼・消化管等から物質を除去し吸収を減らすこと | routineに行わず、airway・物質・時間・二次曝露を評価 |
| antidote | 特定毒性を打ち消す治療薬 | 適応、dose、monitor、反復、rebound、在庫を確認する |
| enhanced elimination | dialysis等で毒物除去を増やす治療 | 物質特性と臨床重症度、時期、資源を統合する |
| rebound toxicity | antidote終了や再分布後に毒性が再燃すること | antidote作用時間と毒物の吸収・半減期を比較する |

**新人看護師の到達点：** 容器・処方・曝露時刻/経路・量の不確実性・併用物質・意図を整理し、意識、瞳孔、分泌、皮膚、体温、呼吸、ECG、glucoseを反復記録する。二次曝露を防ぎ、無理に嘔吐を誘発しない。

> **報告例：** 「意識低下、縮瞳、呼吸数低下があります。曝露物質と量は不明で、opioid-like toxidromeを疑います。airway/ventilationを支援し、antidote反応と再鎮静を監視しながら中毒専門家へ相談してください。」

**ベテラン向け深掘り：** urine drug screenや単回正常ECGをrule-outにせず、extended-release、patch、body packing、active metabolite、臓器不全、混合摂取を考慮する。除染・antidote・eliminationは利益とaspiration、手技、供給・転送riskを比較する。

```text
scene/staff safety → ABCDE + glucose + temperature
→ exposure history/container/time/route → toxidrome + ECG/labs
→ supportive care → poison center/toxicologist early
→ selective decontamination/antidote/elimination → serial reassessment
```

## Toxidrome is a hypothesis

意識、瞳孔、皮膚/発汗、分泌、腸蠕動、体温、HR/BP、呼吸、筋緊張を組み合わせる。混合摂取、遅延吸収、処方薬、離脱、感染/代謝/脳疾患を常に並行鑑別する。

## Exposure representation

`who / substance or class / formulation / amount uncertainty / route / time / intent / co-exposure / symptoms and trajectory / prehospital treatment`を一文にする。extended-release、patch、body packing、plant/chemical、occupational exposureは遅延・二次曝露を考える。

## Pattern table—not a diagnosis

| Pattern | Typical cluster | Immediate threats to seek |
|---|---|---|
| Opioid-like | CNS/respiratory depression、miosis | hypoventilation、aspiration、recurrent toxicity |
| Sympathomimetic | agitation、mydriasis、sweating、tachycardia、hyperthermia | ischemia、seizure、rhabdomyolysis |
| Anticholinergic | delirium、mydriasis、dry/hot skin、retention | hyperthermia、dysrhythmia、seizure |
| Cholinergic | secretions、bronchorrhea、miosis、GI activity、weakness | airway flooding、bronchospasm、neuromuscular failure、staff exposure |
| Sedative-hypnotic | CNS/respiratory depression、ataxia | airway loss、hypotension、mixed ingestion |

patternが合わない所見は「例外」と捨てず、mixed exposureまたはnon-toxicologic mimicの手掛かりにする。

## Bedside priorities

- airway/ventilation、shock、seizure、dysrhythmia、temperature、glucose/electrolyteを先に安定化する。
- serial ECG（rate、rhythm、QRS、QT）、acid-base、organ injuryと経時変化を追う。screening testの陰性だけで除外しない。
- decontaminationはroute/time、airway、物質特性、staff exposureを評価して選択する。routineに行わない。
- antidoteは適応、timing、dose、contraindication、monitoring、在庫を専門家/最新protocolで確認する。心停止前の早期相談が重要。

## Minimum diagnostic dataset

history/scene evidence、serial vital/neurologic exam、glucose、core temperature、12-lead/serial ECG、acid-base/electrolyte/renal-liver injuryを基本に、妊娠可能性や特定濃度は曝露と治療可能性に応じ選ぶ。broad urine drug screenの陽性/陰性を原因確定や除外に使わない。

## Decontamination decision

1. staff/scene contaminationはあるか—PPE、脱衣、区域分離、専門hazmat。
2. skin/eye exposureはあるか—物質に適した早期irrigation/除去。
3. GI decontaminationで吸収を意味ある程度減らせるか。
4. airway/aspiration、corrosive/hydrocarbon、ileus/obstruction等の害は上回らないか。
5. poison center/toxicologistと方法・timing・endpointを共有したか。

## Antidote and enhanced elimination check

適応となるtoxicity、diagnostic uncertainty、time window、dose source、preparation、endpoint、adverse effect、repeat/infusion、rebound、在庫/transferを確認する。dialysis/hemoperfusion等は物質特性だけでなく臨床重症度、organ function、timing、access/resourceを専門家と判断する。

## Observation and disposition

half-lifeだけでなくformulation、dose uncertainty、metabolite、co-ingestion、organ dysfunction、decontamination、antidote duration、rebound、intent/mental health、安全なfollow-upで観察期間を決める。初期無症状や一回の正常ECGだけで退院を決めない。

> [!DANGER]
> unknown ingestionで嘔吐を誘発しない。容器や薬剤を直接嗅がず、二次曝露を防ぐ。中毒情報機関・medical toxicologistへ早期相談する。
