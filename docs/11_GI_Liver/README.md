# 11 GI, Liver and Pancreas

## 推奨学習順序

1. [急性消化管出血](GI_Bleeding/ACUTE_GI_BLEEDING.md)で蘇生・止血・再出血を学ぶ。
2. [急性肝不全・肝性脳症](Acute_Liver_Failure/ACUTE_LIVER_FAILURE_HE.md)で原因検索と早期移植相談を学ぶ。
3. [急性膵炎](Pancreatitis/ACUTE_PANCREATITIS.md)で臓器不全、輸液、栄養、壊死を学ぶ。
4. [腹腔内圧上昇・腹部compartment syndrome](IAH_ACS/INTRA_ABDOMINAL_HYPERTENSION.md)で測定と減圧判断を学ぶ。

各章は病名だけでなく、出血・意識・灌流・腹腔内圧などの生理的変化と介入後の再評価を中心に構成している。
