# 17 Infection Control

## 推奨学習順序

1. [標準予防策と感染経路別予防策](Precautions/STANDARD_TRANSMISSION_PRECAUTIONS.md)で全患者への基本策と早期隔離を学ぶ。
2. [Device関連感染予防](Device_Infection_Prevention/DEVICE_INFECTION_PREVENTION.md)で挿入・access・維持・抜去のlifecycleを学ぶ。

感染対策はPPEだけでなく、環境、device、staffing、患者・家族communication、職業曝露後対応まで含む。
