# Device-associated Infection Prevention

## Universal device lifecycle

```text
valid indication → aseptic insertion → closed/secure maintenance
→ daily necessity + site/function review → prompt removal
→ suspected infection: patient first + cultures/source decision + device plan
```

## Central lines

maximal sterile barrier、appropriate skin antisepsis、site selection/risk、ultrasound competency、hub/connector disinfection、dressing integrity、dedicated access behaviorをbundle化する。毎日necessityとline consolidationを行い、routine scheduled replacementを感染予防の代替にしない。

## Urinary catheters

適応を限定し、aseptic insertion、smallest appropriate catheter、closed drainage、unobstructed dependent flow、bagを床から離す。urine odor/cloudinessやpyuriaだけでCAUTIと診断/培養せず、症状とalternative sourceを評価する。

## Artificial airway / ventilation

head positioning、oral care、sedation/SBT/extubation readiness、subglottic secretion等をdevice/patientに応じbundle化する。VAE/VAP surveillance definitionとbedside clinical diagnosisを混同しない。[Artificial Airway Care](../../01_Airway/Artificial_Airway_Care/ARTIFICIAL_AIRWAY_CARE.md)をSSOTとする。

> [!CAUTION]
> “device culture positive＝infection”でも“culture negative＝device retained”でもない。specimen quality、clinical syndrome、biofilm/source control、device necessityをID/IPCと統合する。

## Drain/circuit/access points

access回数を減らし、closed system、aseptic sampling、securement、dressing、label/dateを維持する。disconnect/leak/breakを記録し、交換riskと感染riskを専門teamで比較する。
