# Device-associated Infection Prevention

## 0. まず覚える

device関連感染予防は、挿入時の無菌操作だけでなく、**正しい適応、accessごとの清潔操作、closed system、毎日の必要性確認、早期抜去**を通したlifecycle管理である。

**簡単に言うと：** 「入れた日」だけでなく、「触るたび」「毎日残すたび」に感染riskを管理する。

| 用語 | 意味 | 実践上のポイント |
|---|---|---|
| CLABSI | central line-associated bloodstream infection | surveillance定義と個々の患者の感染診断を混同しない |
| CAUTI | catheter-associated urinary tract infection | 混濁・臭い・pyuriaだけで診断や培養を行わない |
| VAP / VAE | 人工呼吸関連肺炎 / 人工呼吸関連event | surveillanceとbedside clinical diagnosisを区別する |
| insertion bundle | 挿入時の複数の感染予防策 | barrier、皮膚消毒、部位、competencyをまとめて実施 |
| maintenance bundle | 維持中のaccess・dressing・closed system等の予防策 | accessのたびをaseptic eventとして扱う |
| biofilm | device表面に形成される微生物の膜状集団 | 抗菌薬だけで除去できずsource controlが必要なことがある |

**新人看護師の到達点：** deviceごとに適応、部位、挿入日、固定・dressing、closed system、最終access、培養、抜去barrierを確認する。disconnectや汚染を記録し、不要deviceの抜去を提案できる。

> **報告例：** 「中心lineの適応は終了していますが残存し、dressing剥離とhub access増加があります。感染徴候はありません。不要deviceとして本日抜去できるか確認してください。」

**ベテラン向け深掘り：** culture陽性＝自動抜去、陰性＝自動温存とせず、検体品質、colonization、病原体、tunnel/pocket、biofilm、代替access riskを統合する。bundle遵守率だけでなく実際のprocess observationとfeedbackを行う。

## Universal device lifecycle

```text
valid indication → aseptic insertion → closed/secure maintenance
→ daily necessity + site/function review → prompt removal
→ suspected infection: patient first + cultures/source decision + device plan
```

## Central lines

maximal sterile barrier、appropriate skin antisepsis、site selection/risk、ultrasound competencyをinsertion bundleにし、checklistで中断権限を共有する。hub/connectorは製品所定の摩擦・乾燥時間を守り、各accessをaseptic eventとして扱う。site/dressing integrity、tubing、不要lumen、採血/投薬動線をmaintenance bundleで監査する。毎日necessityとline consolidationを行い、routine scheduled replacementを感染予防の代替にしない。

## Urinary catheters

適応を限定し、代替手段を検討して、aseptic insertion、smallest appropriate catheter、securement、closed drainage、unobstructed dependent flow、bagを床から離す。disconnectとsampling-port accessを最小化し、閉塞・leak時は原因を評価する。urine odor/cloudinessやpyuriaだけでCAUTIと診断/培養せず、症状、採取方法、alternative sourceを評価してculture stewardshipを行う。

## Artificial airway / ventilation

head positioning、oral care、sedation/SBT/extubation readiness、subglottic secretion等をdevice/patientに応じbundle化する。ventilator circuitは汚染/故障等の適応時に交換し、condensateを患者側へ流さず、吸引・口腔care時のcross-contaminationを防ぐ。VAE/VAP surveillance definitionとbedside clinical diagnosisを混同しない。[Artificial Airway Care](../../01_Airway/Artificial_Airway_Care/ARTIFICIAL_AIRWAY_CARE.md)をSSOTとする。

> [!CAUTION]
> “device culture positive＝infection”でも“culture negative＝device retained”でもない。specimen quality、clinical syndrome、biofilm/source control、device necessityをID/IPCと統合する。

## Drain/circuit/access points

access回数を減らし、closed system、aseptic sampling、securement、dressing、label/dateを維持する。disconnect/leak/breakを記録し、交換riskと感染riskを専門teamで比較する。

## When device infection is suspected

1. まずshock/呼吸不全を安定化し、抗菌薬を有意に遅らせない範囲で適切な末梢血・device関連検体を採る。
2. 感染以外の原因、検体汚染、colonization、別sourceを並行評価する。
3. `retain / remove / exchange / drain`をdevice necessity、tunnel/pocket、病原体、biofilm、血行動態、代替accessのriskから決め、source control時刻を記録する。
4. 培養結果と臨床反応で抗菌薬・device planを再評価し、「陽性だから抜去」「陰性だから温存」の自動判断を避ける。

## Daily device card

deviceごとに、適応、種類/部位、挿入日、最終access、site/dressing、機能、培養/感染疑い、今日のremoval barrierと責任者をroundで読み上げる。bundle遵守は結果指標だけでなくprocess observationとfeedbackで改善する。
