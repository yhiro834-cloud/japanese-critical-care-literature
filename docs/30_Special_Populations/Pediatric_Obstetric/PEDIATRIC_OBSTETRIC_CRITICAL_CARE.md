# Pediatric and Obstetric Critical Care

## 共通原則

```text
ABCDE → 年齢/妊娠週数・体格・baselineを確認
→ 成人基準との差を明示 → pediatric/obstetric specialistを早期招集
→ patient-specific order・機器・薬量をdouble-check → responseを再評価
```

## Pediatric differences

- 年齢別正常値、体重、気道径、呼吸仕事量、循環代償を前提にする。低血圧は遅い徴候になり得る。
- 見た目、呼吸、皮膚循環とABCDEを併用し、保護者からbaseline、摂取、尿量、曝露、発症経過を得る。
- equipment、fluid、drug、defibrillationは体重/体格依存。推定体重を用いた場合は明記し、計算・濃度・上限を独立照合する。
- family presenceと発達段階に応じた説明を組み込む。成人用protocolをそのまま適用しない。

## Pregnancy and postpartum differences

- 妊娠による呼吸・循環・凝固・腎機能・ABGのbaseline変化を考慮する。母体蘇生を最優先し、胎児評価を母体治療の遅延理由にしない。
- 妊娠週数、分娩/産褥日、出血、疼痛、頭痛/視覚症状、血圧、薬剤・麻酔歴を確認する。
- obstetrics、anesthesia、neonatal、critical careを早期に同じmental modelへ揃える。画像・薬剤・搬送のriskは「実施」と「遅延」の双方を比較する。
- 急変時は左方子宮偏位等の妊娠特有の修正と、施設のmaternal arrest/major obstetric hemorrhage pathwayを用いる。

> [!DANGER]
> 小児・妊産婦の具体的dose、tube/device size、蘇生手順は年齢・体重・妊娠週数と最新の専門protocolで確認する。本ページ単独で実施しない。
