# Temporary MCS: IABP and Microaxial Flow Pump

## 0. まず覚える

temporary MCS（temporary mechanical circulatory support、一時的機械的循環補助）は、重症心原性shockで心臓と循環を一時的に支えるdevice群である。**device名から選ぶのではなく、どの心室が、どの程度破綻し、何までつなぐのかを先に決める。**

**簡単に言うと：** 装置のflowや血圧ではなく、臓器への血流が改善したか、合併症が増えていないか、次の出口があるかで効果を判断する。

| 用語 | 意味 | 実践上のポイント |
|---|---|---|
| MCS | mechanical circulatory support、機械的循環補助 | deviceごとに支える心室、flow、oxygenation、合併症が異なる |
| IABP | intra-aortic balloon pump、大動脈内balloon pump | 拡張期にinflation、収縮期直前にdeflationして冠灌流と後負荷を補助 |
| microaxial flow pump | 心室内から大動脈へ血液を送る軸流pump | position、preload、RV機能、support levelでflowが変化する |
| unloading | 心室内の容量・圧負荷を減らすこと | 肺うっ血、心室径、弁開放、灌流と合わせて評価する |
| hemolysis | 回路・pumpで赤血球が破壊されること | 暗色尿、LDH/plasma-free Hb、腎機能、device条件を確認 |
| purge system | microaxial pump内部を保護する専用液・圧管理系 | systemic anticoagulationとは別に内容・圧・alarmを確認する |

**新人看護師の到達点：** device種、support level、挿入部、末梢循環、波形/console、出血、溶血、尿量、調律、血管作動薬を基準値と比較する。alarm時はまず患者のpulse・灌流を確認し、device specialistを呼び、自己判断でpositionや設定を変更しない。

> **報告例：** 「microaxial pumpでsuction alarmが反復し、尿量低下と暗色尿があります。血圧波形のpulsatilityも低下しています。position、preload/RV failure、出血、hemolysisを含む緊急評価をお願いします。」

**ベテラン向け深掘り：** IABP augmentationや推定pump flowを臓器灌流の代用にせず、echo、invasive hemodynamics、lactate、尿量、意識、薬剤需要を統合する。escalation/reconfiguration/weaningは1時間・24時間のtrajectoryで更新し、recovery、durable support、移植、緩和を含むexit strategyを明示する。

## Device follows phenotype

temporary MCSは血圧の数字を上げる目的だけで選ばない。LV/RV/biventricular failure、oxygenation、vascular anatomy、valve/aorta、arrhythmia、shock stage、neurological prognosis、reversibilityと**exit strategy**をshock teamで明示する。

## IABP

diastolic inflationとsystolic deflationでcoronary perfusion/afterloadを補助する。効果はrhythm、timing、native functionに依存し、提供flowは限定的。trigger/timing、augmentation、balloon position、limb perfusion、bleeding、platelet、infectionを監視する。

arterial waveform/ECG triggerとinflation-deflation timingを患者のpulse/perfusionと照合する。頻脈、不整脈、低拍出でaugmentation値だけを効果判定に使わない。大動脈病変・高度AR等の禁忌/害を挿入前に確認する。

## Microaxial flow pump

LVからaortaへflowを送りLV unloadingを図る。position、preload/RV function、afterload、RPM/support levelに依存する。suction、migration、hemolysis、aortic/mitral injury、bleeding、limb ischemia、anticoagulationを監視する。

console表示flowは推定値で、全身灌流そのものではない。echo position、native aortic valve opening、arterial pulsatility、lactate/尿量/意識、RVと肺循環をserialに統合する。purge systemとsystemic anticoagulationを別々に確認し、hemolysis trendと腎障害を早期に拾う。

> [!CAUTION]
> “flow alarm＝fluid”ではない。position、RV failure、tamponade、bleeding、arrhythmia、ventilation pressure、device thrombosis等を確認する。routine MCSではなく選択患者の利益とvascular/bleeding riskを比較する。

## Daily device round

- indication/bridge、shock trajectory、end-organ response
- device type/position/support、native pulsatility/echo
- access/limb/bleeding、hemolysis、anticoagulation
- preload/RV/LV/oxygenation、vasoactive need
- escalation、weaning trial、explant/transition criteria

## Emergency principles

alarm時はpatient/pulse/perfusionを先に確認し、device specialistを呼ぶ。positionやsupport変更はdevice-specific protocolに従う。cardiac arrestではdevice configurationを理解したcurrent resuscitation algorithmを用い、胸骨圧迫可否やimagingをteamで即時判断する。

```text
patient/perfusion → power/console → position → preload/RV → afterload/rhythm
→ access/bleeding/hemolysis → device-specific action → response
```

搬送時は電源・battery、予備console/部品、酸素、薬剤、固定、緊急連絡、受入先を確認する。毎日、回復、durable support、移植、緩和を含むexit strategyと「次の判断期限」を更新する。
