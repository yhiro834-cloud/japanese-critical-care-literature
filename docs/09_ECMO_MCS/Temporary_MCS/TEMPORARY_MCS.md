# Temporary MCS: IABP and Microaxial Flow Pump

## Device follows phenotype

temporary MCSは血圧の数字を上げる目的だけで選ばない。LV/RV/biventricular failure、oxygenation、vascular anatomy、valve/aorta、arrhythmia、shock stage、neurological prognosis、reversibilityと**exit strategy**をshock teamで明示する。

## IABP

diastolic inflationとsystolic deflationでcoronary perfusion/afterloadを補助する。効果はrhythm、timing、native functionに依存し、提供flowは限定的。trigger/timing、augmentation、balloon position、limb perfusion、bleeding、platelet、infectionを監視する。

## Microaxial flow pump

LVからaortaへflowを送りLV unloadingを図る。position、preload/RV function、afterload、RPM/support levelに依存する。suction、migration、hemolysis、aortic/mitral injury、bleeding、limb ischemia、anticoagulationを監視する。

> [!CAUTION]
> “flow alarm＝fluid”ではない。position、RV failure、tamponade、bleeding、arrhythmia、ventilation pressure、device thrombosis等を確認する。routine MCSではなく選択患者の利益とvascular/bleeding riskを比較する。

## Daily device round

- indication/bridge、shock trajectory、end-organ response
- device type/position/support、native pulsatility/echo
- access/limb/bleeding、hemolysis、anticoagulation
- preload/RV/LV/oxygenation、vasoactive need
- escalation、weaning trial、explant/transition criteria

## Emergency principles

alarm時はpatient/pulse/perfusionを先に確認し、device specialistを呼ぶ。positionやsupport変更はdevice-specific protocolに従う。cardiac arrestではdevice configurationを理解したcurrent resuscitation algorithmを用い、胸骨圧迫可否やimagingをteamで即時判断する。
