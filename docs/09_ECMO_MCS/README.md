# 09 ECMO and Mechanical Circulatory Support

## 推奨学習順序

1. [ECMOの基礎と日常管理](ECMO_Foundations/ECMO_FOUNDATIONS_DAILY_MANAGEMENT.md)でVV/VA、flow、sweep、bridgeを学ぶ。
2. [ECMO緊急時troubleshooting](ECMO_Emergencies/ECMO_EMERGENCY_TROUBLESHOOTING.md)で「患者優先」と原因別初動を学ぶ。
3. [一時的MCS](Temporary_MCS/TEMPORARY_MCS.md)でIABPとmicroaxial flow pumpの目的・観察・出口を学ぶ。

本文は装置を初めて学ぶ看護師の観察から、shock teamが考えるphysiologyとexit strategyまで段階化している。装置固有の操作は必ず施設のmanual、emergency card、訓練を優先する。
