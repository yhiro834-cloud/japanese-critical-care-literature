# 07 Trauma and Burns

## 推奨学習順序

1. [外傷初期評価](Initial_Assessment/TRAUMA_INITIAL_ASSESSMENT.md)で`<C>ABCDE`と再評価loopを学ぶ。
2. [外傷性大出血とdamage control](Hemorrhage_Damage_Control/TRAUMA_HEMORRHAGE_DAMAGE_CONTROL.md)で止血・MTP・lethal diamondを学ぶ。
3. [熱傷初期管理](Burns/BURN_INITIAL_MANAGEMENT.md)で吸入損傷、TBSA、輸液と保温を学ぶ。
4. 頭部外傷は[ICP / CPP / TBI](../04_Neurology/ICP_CPP_TBI/ICP_CPP_TBI.md)へ進む。

各章は「まず覚える→用語→新人看護師の到達点→ベテラン向け深掘り→詳細」の順で読める。英語は国際的に共有される略語・検索語を日本語説明と併記する。

## Safety boundary

成人外傷・熱傷の初期認識とteam reasoningを扱う。施設のtrauma activation、massive transfusion、手術/IVR、burn center転送protocolを置き換えない。
