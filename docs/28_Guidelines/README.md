## Status

- `candidate`: 候補。Knowledgeの根拠として未採用
- `verified-current`: 公式サイトで題名・版・年・URLを確認
- `superseded`: 新版に置換。履歴として保持
- `withdrawn`: 発行元が撤回
- `access-check-needed`: URLまたは公開状態の再確認が必要

## 登録時チェック

- [ ] 発行組織の公式サイトで確認した
- [ ] 完全な題名、発行年、版/更新を照合した
- [ ] 対象集団とscopeを記録した
- [ ] 前版・追補・living updateとの関係を確認した
- [ ] DOI/PMIDは存在する場合のみ原典で照合した
- [ ] Knowledgeページのどの主張に使用したかリンクした

## 優先登録領域

Sepsis、ARDS/ventilation、resuscitation、AKI/RRT、pain/sedation/delirium、nutrition、trauma、neurocritical care、ECMO/MCS、infection preventionをPhase 2で公式情報から確認します。
