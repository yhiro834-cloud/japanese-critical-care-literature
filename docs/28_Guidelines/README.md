## Status

- `candidate`: 候補。Knowledgeの根拠として未採用
- `verified-current`: 公式サイトで題名・版・年・URLを確認
- `superseded`: 新版に置換。履歴として保持
- `withdrawn`: 発行元が撤回
- `access-check-needed`: URLまたは公開状態の再確認が必要
