# 10 Endocrine and Metabolic

## 推奨学習順序

1. [DKA / HHS](Hyperglycemic_Crises/DKA_HHS.md)でketosis、acidosis、浸透圧、Kを学ぶ。
2. [重症患者の血糖管理](Glycemic_Control/ICU_GLYCEMIC_CONTROL.md)で安全なinsulin・栄養・測定管理を学ぶ。
3. [内分泌・体温緊急症](Endocrine_Emergencies/ENDOCRINE_TEMPERATURE_EMERGENCIES.md)で検査を待てない症候群と温度管理を学ぶ。

各章は日本語を主とし、代謝の因果関係を「値→患者への影響→観察→報告→再評価」の順で理解できる構成にしている。
