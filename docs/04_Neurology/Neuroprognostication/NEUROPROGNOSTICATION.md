# Neuroprognostication After Cardiac Arrest

> [!CAUTION]
> 予後評価は生命維持治療の判断と自己成就的予言に直結します。早期・単一検査・交絡下の断定を避け、経験あるmultidisciplinary teamが家族の価値観と不確実性を含め判断します。brain death/death by neurologic criteriaとは別processです。

## 1. Principles

NCS 2023は、ROSC後少なくとも72時間（低体温療法を用いた場合はrewarming後少なくとも72時間）待つこと、sedation等の交絡なし、multimodal assessment、回復に長い時間がかかり得ること、不確実性の明示をgood practiceとして示します。72時間で覚醒しないこと自体はpoor outcome確定ではありません。

## 2. Confounders and Modalities

- sedative/analgesic/NMB、temperature、shock、organ failure、metabolic/toxic state
- serial neurological exam（pupil等）
- EEG timing/pattern/reactivityとmedication
- SSEP
- CT/MRI patternとtiming
- biomarkers（NSE等）は測定法/threshold/hemolysis等の限界

各所見のreliabilityとfalse-positive riskはtiming・方法で異なります。相互に独立した複数modalitiesが整合するかを評価します。

## 3. Clinical Reasoning

```text
coma after ROSC → ongoing careと原因治療 → timingを確認
→ sedation/temperature/organ failure等を除外
→ standardized exam + EEG/SSEP/imaging/biomarker
→ concordanceと不確実性 → goals/valuesを含むfamily meeting
→ indeterminateなら観察延長と再評価
```

## 4. Communication and Nursing

- “まだ分からない”と“回復不能”を区別し、検査目的と時間軸を説明
- sedation/NMB/temperature/awakening trialを正確に記録
- spontaneous movement、command following、myoclonus、pupil、EEG eventを時刻化
- 家族の理解、希望、宗教/文化、patient valuesを多職種で共有
- organ donation discussionやbrain death testingを予後予測と混同しない

## 5. Red Flags / Pitfalls

- 72時間未満や鎮静蓄積下の断定、myoclonus単独、単一NSE threshold、悪いCT一枚だけ
- prognosisとWLSTを同じ人・同じ瞬間に短絡、家族へcertaintyを誇張
- functional outcomeを患者の価値観なしに“poor”と定義

## 6. Take Home Messages

1. delay、deconfound、multimodalが基本。
2. indeterminate prognosisは失敗でなく正直な結論。
3. 予後予測、brain death、goals-of-careは区別する。
