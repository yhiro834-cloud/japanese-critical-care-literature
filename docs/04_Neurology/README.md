## ベテラン看護師の学習焦点

- scoreの合計ではなくcomponent、左右差、刺激条件、trendを扱う。
- 脳だけでなく酸素化、PaCO₂、MAP、体温、Na、薬剤を二次性脳損傷へ統合する。
- 画像・ICP・EEG・予後指標の測定限界と自己成就的予言を理解する。
