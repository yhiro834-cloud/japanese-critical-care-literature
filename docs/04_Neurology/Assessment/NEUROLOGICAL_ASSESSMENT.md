# Neurological Assessment in Critical Care

> [!CAUTION]
> 意識変化は神経疾患だけでなく低酸素、低灌流、低血糖、薬剤、CO₂、感染、電解質異常で起こります。新規の瞳孔不同・局在徴候・急速なGCS低下は直ちにescalationしてください。

## 0. まず覚える

**神経学的評価**は、意識・瞳孔・眼球・言語・運動・感覚などを同じ条件で繰り返し、基準値からの変化を捉える評価です。

**簡単に言うと：** 合計点を記録するのではなく、「いつ、どの刺激で、どの反応が、左右どのように変わったか」を伝えます。

| 用語 | 意味 | 注意 |
|---|---|---|
| GCS | 開眼・言語・運動反応の尺度 | E/V/Mを個別記録し、評価不能を推測しない |
| JCS | 日本で用いられる意識尺度 | 詳細な神経所見を置き換えない |
| pupil | 瞳孔 | 径、左右差、形、対光反射、測定条件を記録 |
| focal deficit | 局在性神経症状 | 顔面・上下肢・言語・視野等の左右差 |

**新人看護師の到達点：** ABCと血糖を先に確認し、GCS各項目、瞳孔、左右差、鎮静薬、変化時刻をそろえて報告すること。

**ベテラン向け深掘り：** 薬剤蓄積、低体温、臓器不全、NMB、眼疾患、baseline障害を交絡として分離し、画像・EEG・ICP等へ接続します。

### 報告例

> 「最終正常○時、○時に変化を確認しました。GCSはE○V○M○で前回から○、瞳孔は右○mm/左○mm・反応○○、顔面と四肢の左右差は○○です。SpO₂、血圧、血糖、PaCO₂、鎮静薬は○○です。」

## 1. Overview

神経評価は一度のscoreでなく、baseline、刺激条件、鎮静/挿管/麻痺、左右差、時間変化を再現可能に記録するprocessです。ABCDE安定化とcause searchを同時に行います。

## 2. Structured Examination

- 覚醒/attention、orientation、言語、命令への反応
- GCSはE/V/M各componentを記載。挿管等で評価不能な項目を合計点で推測しない
- JCSは施設内communicationに有用だが、世界的比較や詳細componentを置き換えない
- pupils：左右径、shape、light response、測定条件。pupillometer値はtrend補助
- gaze、顔面、四肢motor/sensory、tone、reflex、ataxia（可能時）
- breathing pattern、temperature、meningism、trauma sign

## 3. Confounders

sedative/analgesic、neuromuscular blocker、hypothermia、organ failureによる薬剤蓄積、intoxication、眼疾患/手術、ambient light、hearing/language、pre-existing deficitを明記します。

## 4. Clinical Reasoning

```text
意識変化 → ABCDE/血糖 → baselineとlast-known-well → pupils/局在/けいれん
→ 薬剤・代謝・感染・構造病変 → 緊急画像/EEG/検査
→ 原因介入 → 同じ条件でserial examination
```

## 5. Nursing Points

- assessment前にsedation/analgesia/NMBの時刻とdose、体温、glucose、PaCO₂を確認
- “GCS 8”だけでなく`E2 Vt M5`のようにcomponentと制約を記録
- pupil変化はmm、反応、左右、時刻、直前薬剤/処置を含め報告
- suction、turning、transport前後のICP/neurological responseを比較
- sleepとdelirium assessmentを神経悪化と混同せず並行

## 6. Red Flags / Pitfalls

- new anisocoria、fixed pupil、Cushing pattern、new weakness/gaze deviation、急速な低下
- sedationと決めつける、合計GCSだけ、痛み刺激を過剰反復、左右差を記録しない

## 7. Take Home Messages

1. component・左右差・交絡・trendを記録する。
2. 神経悪化でもABCDEと可逆的全身原因を先に確認する。
3. last-known-wellと変化時刻は治療選択に直結する。
