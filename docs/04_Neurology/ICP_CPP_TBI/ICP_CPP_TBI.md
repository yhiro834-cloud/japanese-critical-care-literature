# ICP, CPP, Cerebral Edema, and Severe TBI

> [!CAUTION]
> impending herniationはclinical emergencyです。hyperosmolar therapy、ventilation、surgery等は病態・monitor・循環・電解質を踏まえ専門チームと施設protocolで実施します。固定用量や単一CPP targetを本頁から処方しません。

## 1. Physiology

頭蓋内volumeは脳実質・血液・CSFで構成され、代償域を超えると小さなvolume増加でICPが急上昇します。`CPP = MAP − ICP`（CVPがICPより高い等では単純式に限界）。PaCO₂、oxygenation、temperature、seizure、venous drainage、metabolismがCBF/ICPへ影響します。

## 2. Assessment and Monitoring

- serial neuro/pupil、ICP waveform/value、CPP/MAP、position
- oxygenation、PaCO₂、temperature、glucose、Na/osmolality、renal function
- EVD level/zero、patency、CSF drainage、insertion site
- CT trend、EEG、brain tissue oxygen等は適応と専門性に応じる
- BTF 4th editionのthresholdは集団指針で、年齢/autoregulation/systemic injuryを含め個別化

## 3. Prevention of Secondary Injury

airway/oxygenation、低血圧回避、head/neck alignment、適切なanalgesia/sedation、fever/seizure/glucose管理、venous outflow、必要なsurgery/CSF drainageを統合します。routine prolonged hyperventilationはischemia riskがあり、herniationへの短時間bridge等の明確な目的とmonitoringを要します。

NCS 2020は原因疾患別にhypertonic sodium solution、mannitol等を評価し、evidenceの多くが低確実性です。agent choiceはvolume、Na/osmolality、renal、access、causeで決め、臨床/ICP responseと害を監視します。corticosteroidはTBI cerebral edemaのroutine治療ではありません。

## 4. Clinical Reasoning

```text
neuro/ICP悪化 → artifact/level/position → ABCDE・pupil・herniation signs
→ airway/CO₂/O₂/MAP/temperature/seizure/venous outflow
→ mass lesion/hydrocephalus/edemaを再評価
→ temporizing + definitive intervention → ICP/CPPと全身灌流を再評価
```

## 5. Nursing Points

- EVDは基準点とorderを体位変更ごとに確認し、無断でclamp/開放/flushしない
- suction/turning/bathingをbundle化せず、stimulusとICP recoveryを評価
- neck midline、tube/tie、腹圧、咳、pain、agitation、feverを最適化
- hyperosmolar therapy前後のNa/osmolality、urine、BP、renal、lineを確認
- acute changeはmonitor値だけでなくpupil/GCS/介入/時刻をclosed-loop報告

## 6. Red Flags / Pitfalls

- fixed/dilating pupil、extensor response、急なICP elevation、CPP低下、Cushing pattern
- ICP数字だけを治療、EVD level error、低血圧を伴う過剰鎮静/diuresis、routine hyperventilation

## 7. Take Home Messages

1. CPPはMAPとICPの両方を含むが、臓器全体を見て個別化する。
2. secondary injury preventionは酸素・血圧・CO₂・体温・seizure・venous drainageのbundle。
3. emergency bridgeとdefinitive cause controlを区別する。
