# Systematic ICU Assessment

## Three passes

### 1. Immediate threats

ABCDE、monitor validity、airway/device connection、active infusion、bleeding、glucose、temperatureを確認し、必要な救命介入を開始する。

### 2. Trajectory and organ systems

発症前baseline→入室理由→現在までのresponseを時系列化し、neuro、respiratory、cardiovascular/perfusion、renal/fluid/electrolyte、infection、GI/nutrition、hematology、skin/mobility、pain/sedation/deliriumを確認する。

### 3. Plan integrity

各problemにworking diagnosis、goal、intervention、monitor、stop/escalation trigger、owner、timeを割り当てる。不要device、duplicate drug/test、未回収culture/result、予防、家族/goal、transfer readinessも確認する。

## Head-to-toe plus devices

| Domain | Observe/verify | Reasoning question |
|---|---|---|
| Neuro/comfort | consciousness, pupils, pain, sedation, delirium, sleep | drug、brain lesion、metabolic、withdrawalのどれか |
| Airway/breathing | patency, tube, effort, SpO₂/ETCO₂, waveform, gas | oxygenation/ventilation/workのどこが変化したか |
| Circulation | rhythm, pulse, MAP, CRT/skin, flow, congestion | preload/pump/rate/tone/obstruction、mixed shockか |
| Renal/metabolic | urine trend, fluid balance, weight, electrolytes, glucose | production低下、obstruction、clearance/iatrogenicか |
| Infection | syndrome, cultures, antimicrobial timing, source | infection probability、source control、mimicは何か |
| GI/nutrition | abdomen, feeding tolerance, bowel, liver | perfusion、bleeding、aspiration/refeeding riskは何か |
| Hematology | bleeding/thrombosis, counts, coagulation, devices | consumption、drug、dilution、immune/mechanicalか |
| Skin/mobility | pressure, wounds, edema, positioning, function | preventable harmと今日のmobility goalは何か |
| Lines/devices | indication, insertion/site, connection, setting, backup | 今日も必要か、failure時の代替はあるか |

## Daily goals card

各shift/roundで以下を一画面または一枚に集約する。

- today’s dominant threat and trajectory
- oxygen/ventilation、perfusion、neuro/comfort、fluid/nutrition、infectionのgoal
- liberation：sedation、ventilator、vasoactive、device、mobility
- pending test/resultとowner/time
- family communication、patient values、treatment limitations
- deterioration triggerとfirst response

## Trend hygiene

baseline、時刻、測定法、position、support setting、介入を揃える。cumulative balance、weight、urine、drug dose、ventilator/vasopressor等は同じtimelineに重ねる。copy-forwardされた所見を再診察所見として扱わない。

## Scores and POCUS

severity/organ dysfunction scoreはpopulation比較やtrajectory補助であり、個人の診断・予後・治療制限を単独で決めない。POCUSはfocused clinical questionに対し、operator/画像品質/限界を記録し、history、exam、他検査と統合する。

POCUSでresuscitationを中断しない。保存画像、view/quality、finding、interpretation、clinical integrationを分け、credentialingとlocal governanceに従う。SCCM 2024 focused updateはseptic shock、acute dyspnea/respiratory failure、targeted volume management、cardiogenic shockでのCCUS利用を条件付きで支持するが、evidence certaintyと適用範囲を確認する。

## Minimum handoff dataset

identity/baseline、code/goals、current threat、trajectory、airway/oxygen/ventilator、hemodynamics/infusions、neuro/sedation、renal/fluid、infection/antimicrobials、lines/drains、pending tasks、contingencyをread-backする。
