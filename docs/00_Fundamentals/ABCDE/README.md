# ABCDE：生命危機を見つけ、介入し、再評価する共通言語

最終Evidence確認: 2026-08-12

対象: 成人の救急・集中治療における初期評価の教育枠組み

Human review required: Yes（施設の急変対応手順、役割分担、小児・妊産婦への適応）

> [!CAUTION]
> ABCDEは診断名を当てる順番ではなく、診断確定を待てない生命危機を見つけて対応する枠組みです。蘇生、気道確保、緊張性気胸への対応など、訓練・権限・施設手順を要する処置はこのページだけで実施しません。

## Quick Review

### 一言でいうと

気道（Airway）、呼吸（Breathing）、循環（Circulation）、神経学的状態（Disability）、全身観察と環境調整（Exposure）の順に生命危機を探し、見つけた問題へ介入し、その効果と害を繰り返し確認する方法です。

**[FACT] [CLM-ABCDE-001]** WHO/ICRCのBasic Emergency Careは、ABCDEを急性疾患・外傷患者の生命危機を迅速に評価し介入する体系として扱っています。[SRC-ABCDE-001]

### 最重要原則

1. 最初に安全、反応、明らかな心停止・大出血を確認する。
2. Aから評価するが、不可逆的な危機への対応を「順番待ち」にしない。
3. 異常を見つけたら、可能な初期対応と応援要請を行う。
4. 処置後は数値だけでなく患者の反応と有害事象を確認する。
5. チームでは評価、モニター装着、ルート確認、記録、連絡を同時並行にできる。

**[PRACTICE] [CLM-ABCDE-002]** 完全な初回評価、定期的な再評価、生命危機を次の項目より先に扱うこと、治療効果の確認、早期の応援要請、チーム活用、構造化コミュニケーションはABCDEの実践原則です。[SRC-ABCDE-002]

## A：気道（Airway）

![ABCDE Airway detail](../../../assets/general/abcde_airway_detail.svg)

**Figure FIG-G-ABCDE-002 — 気道評価**

### 何を確かめるか

- 患者が自然に発声できるか。声の変化、いびき様音、吸気性喘鳴、ゴロゴロした分泌物音がないか。
- 口腔内の異物、嘔吐物、血液、分泌物、顔面・頸部の腫脹がないか。
- 気管チューブや気管切開があれば、深さ、固定、閉塞・屈曲・外れ、カフ、回路接続を確認する。
- 意識低下、疲弊、熱傷、アナフィラキシーなど、今は開通していても悪化し得る要因を考える。

### 危険を疑う所見

発声不能、明らかな閉塞音、努力しているのに空気が動かない、急速な腫脹、人工気道の脱落・閉塞、意識低下に伴う気道防御不良。

### 看護実践

患者から離れず応援を要請し、酸素化と換気を同時に評価します。吸引や体位など施設で認められた初期対応を行った後、胸郭運動、呼吸音、皮膚色、経皮的動脈血酸素飽和度（SpO₂）、呼気終末二酸化炭素（ETCO₂）と患者の反応を再確認します。SpO₂が保たれていても、気道閉塞の進行を否定できません。

## B：呼吸（Breathing）

![ABCDE Breathing detail](../../../assets/general/abcde_breathing_detail.svg)

**Figure FIG-G-ABCDE-003 — 呼吸評価**

呼吸は少なくとも「酸素化」「換気」「呼吸仕事量」に分けて考えます。

| 観察 | 主に示すこと | 主な限界・交絡 |
|---|---|---|
| 呼吸数・深さ・リズム | 呼吸ドライブと換気パターン | 疲弊が進むと努力が減って見える |
| 胸郭運動・左右差 | 換気の分布、胸壁運動 | 肥満、体位、疼痛、ドレープ |
| 呼吸音 | 気流、分泌物、肺・胸腔の異常 | 聴診だけでは病因を確定できない |
| SpO₂と波形 | 動脈血酸素飽和度の推定 | 末梢循環、体動、異常Hb、酸素投与に影響される |
| ETCO₂と波形 | 呼気CO₂、換気・循環・回路の変化 | PaCO₂と常に一致するわけではない |
| 会話、努力呼吸、疲労 | 呼吸予備能と切迫感 | 鎮静、神経筋疾患、意識障害で目立たない |

**[FACT] [CLM-ABCDE-003]** SpO₂だけでは換気不全や呼吸筋疲弊を除外できないため、患者の呼吸仕事量、換気、波形、必要時の血液ガスを統合します。[SRC-ABCDE-001]

急変時は酸素投与量、気道・回路、胸郭、呼吸音、機器表示を確認し、介入前後の患者反応を比較します。単一の酸素目標値はこのページでは規定しません。

## C：循環（Circulation）

![ABCDE Circulation detail](../../../assets/general/abcde_circulation_detail.svg)

**Figure FIG-G-ABCDE-004 — 循環評価**

血圧だけでなく「圧」「血流とポンプ」「組織灌流」「出血・体液」「治療の有害作用」をまとめて評価します。

- 脈拍、リズム、血圧と測定の信頼性。
- 皮膚色・温度、毛細血管再充満時間（capillary refill time: CRT）、末梢脈。
- 意識、尿量、乳酸など臓器灌流の所見と時間変化。
- 外出血、体腔内出血の可能性、ドレーン、便・吐物。
- 静脈路、輸液・輸血・持続薬の接続、残量、ポンプ、閉塞、投与速度。
- 頸静脈、浮腫、肺うっ血など、輸液に耐えられない可能性。

**[UNCERTAINTY] [CLM-ABCDE-004]** 平均動脈圧（mean arterial pressure: MAP）、CRT、尿量、乳酸はいずれも単独では循環不全の原因や治療反応を確定しません。病態、測定条件、推移、介入との時間関係を統合します。[SRC-ABCDE-002]

## D：神経学的状態（Disability）

![ABCDE Disability detail](../../../assets/general/abcde_disability_detail.svg)

**Figure FIG-G-ABCDE-005 — 神経学的評価**

- 呼びかけへの反応と、直前の基準状態からの変化。
- Japan Coma Scale（JCS）またはGlasgow Coma Scale（GCS）。使った尺度を明記する。
- 瞳孔径、左右差、対光反射、明らかな局在徴候。
- 血糖、低酸素、換気不全、低血圧、体温異常、痙攣の可能性。
- 鎮静薬、鎮痛薬、筋弛緩薬、代謝異常など評価をゆがめる要因。

急な意識変化ではA・B・Cへ戻り、低酸素、換気不全、循環不全などの即時可逆因子を同時に探します。意識スコアは状態共有には有用ですが、単独で診断や予後を決めません。

## E：全身観察と環境調整（Exposure）

![ABCDE Exposure detail](../../../assets/general/abcde_exposure_detail.svg)

**Figure FIG-G-ABCDE-006 — 全身観察**

- 必要な範囲を露出し、背面を含む皮膚、外傷、出血、発疹、浮腫、感染源候補を確認する。
- 体温、ドレーン、創部、ライン、尿・便・吐物、患者周囲の薬剤・機器・環境を確認する。
- 観察と同時に保温、尊厳、プライバシー、感染予防を守る。
- 家族・同伴者、救急隊、記録から発症時刻、経過、薬剤、アレルギー、治療制限を補う。

Eは「最後だから重要度が低い」のではありません。大出血、重症感染、アナフィラキシー、熱傷、体温異常などを発見した時点で、チームの優先順位を更新します。

## ICU Nursing Pearls

### 観察

- モニターを見る前後に患者を直接見る。
- 一つの値ではなく、基準状態からの変化、変化速度、複数所見の整合性を見る。
- A〜Eのどこに主問題があり、次に悪化しそうな領域はどこかを言語化する。

### 報告

例: 「5分前から呼びかけへの反応が低下しました。気道音に変化はなく、呼吸数は増加、SpO₂は酸素条件を変えず低下、血圧も低下傾向です。測定不良を確認し、酸素・回路・ルートを再確認しました。至急ベッドサイド評価をお願いします。」

報告には患者識別、現在の生命危機、開始時刻・推移、A〜E所見、行った介入、反応、未解決点、必要な支援を含めます。

### 介入後の再評価

| 確認 | 問い |
|---|---|
| 実施 | 何を、いつ、誰が行ったか |
| 期待 | どの所見が、どの時間内に改善する想定か |
| 反応 | 患者所見と測定値は実際にどう変わったか |
| 害 | 血圧低下、過膨張、意識変化、機器問題など新たな害はないか |
| 次 | 継続、変更、中止、追加評価、上位支援のどれか |

## Troubleshooting

- **患者:** 本当に悪化しているか。気道、呼吸、循環、意識、出血を再評価する。
- **測定:** センサー、カフ、ゼロ点、波形品質、採血条件に誤りがないか。
- **回路・機器:** 外れ、屈曲、閉塞、電源、ガス供給、設定変更がないか。
- **薬剤:** 正しい薬剤・濃度・投与経路・速度か。空、閉塞、漏れはないか。
- **経過:** 介入後に改善したか、変わらないか、悪化したか。

測定エラーを考えても、患者が不安定なら評価と応援要請を止めません。

## Common Pitfalls

1. A〜Eを最後まで読み上げてから危険へ対応する。
2. SpO₂、血圧、GCSなど一つの数値だけを治療する。
3. モニターの正常値を、患者が安定している証拠とみなす。
4. 処置を実施したことで終わり、効果と害を確認しない。
5. チーム内で役割、実施内容、次の悪化時対応を共有しない。
6. Eで保温、尊厳、感染予防を失う。

## Advanced：適用範囲と限界

- ABCDEは原因診断の代わりではありません。生命危機を安定化しながら、病歴、検査、画像、専門診療へ接続します。
- ICUではすでに人工気道、循環作動薬、鎮静、補助循環があるため、デバイスと治療による交絡を各段階で確認します。
- 小児、妊産婦、外傷、熱傷、中毒では生理、基準値、処置、薬剤が異なります。成人の数値・手順をそのまま外挿しません。
- WHO BECは幅広い第一線医療者と資源制約環境も想定した基礎教材です。本ページはICU向けに補足していますが、その補足部分すべてをWHOが個別推奨しているわけではありません。

## Mini Case

人工呼吸中の患者でSpO₂アラームが鳴りました。まず画面の数値だけで酸素濃度を上げるのではなく、患者の反応、胸郭運動、気道・回路、呼吸音、波形、循環を確認します。同時に応援を呼び、原因仮説に応じた介入後、SpO₂だけでなく換気、血圧、意識、機器状態を再評価します。

**問い:** SpO₂が改善しても、どの所見が残れば問題は解決していないと考えますか。

## Take Home Messages

1. ABCDEは順番そのものより、生命危機を見つけて即時対応し、再評価する循環が本質です。
2. 数値より先に患者を見て、数値・波形・診察・経過を統合します。
3. チームで同時並行に動き、介入の効果、害、次の悪化時対応まで共有します。
