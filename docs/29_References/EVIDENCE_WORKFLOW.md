# Evidence Review Workflow

## Candidate → Knowledge

1. **Question:** 対象患者、介入/曝露、比較、アウトカムを定義
2. **Search:** 公式組織、PubMed等の一次情報源を優先
3. **Identity check:** 題名、著者/組織、雑誌、年、版を照合
4. **Identifier check:** DOIはlanding page、PMIDはPubMed recordで照合
5. **Appraisal:** design、population、bias、precision、directness、limitations
6. **Classification:** guideline recommendation / evidence finding / common practice / expert opinion
7. **Link:** どの本文記述を支持するか記録
8. **Review:** clinical・evidence・nursingの観点で確認
9. **Publish:** metadata、Review Log、CHANGELOGを更新
10. **Surveillance:** Next Reviewと新版/訂正/撤回を追跡

## 主張の書き分け

- **Guideline recommendation:** 発行元、版、対象、推奨の強さを原文に忠実に示す
- **Evidence finding:** study designと主要な限界を添える
- **Common clinical practice:** ガイドライン推奨と誤認させない
- **Expert opinion:** 根拠が限定的であることを明示
- **Uncertain:** `Evidence unclear` / `要確認`

## 禁止事項

- Abstractや自動要約だけから詳細な推奨を作る
- 異なる版の推奨を混在させる
- surrogate outcomeを患者重要アウトカムと同一視する
- 相関を因果として書く
- 成人データを小児・妊産婦等へ無条件に外挿する
- 存在未確認のDOI、PMID、URL、Evidence levelを補完する
