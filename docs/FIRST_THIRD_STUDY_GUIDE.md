# 最初の約3分の1を学ぶための案内

この範囲は、基礎、気道、呼吸、循環、神経、腎臓の31本の教科書ページを含む。病名を暗記するより、**患者を直接見る → 測定が正しいか確かめる → 病態を考える → 目的を決めて介入する → 同じ指標で再評価する**順序を身につける。

## 略語の読み方

略語は短く便利だが、意味を理解せず使うと判断を誤る。初出では日本語の正式名称、英語名、略語を一組で確認する。

| 略語 | 正式名称 | 簡単な意味 | 単独で判断しない理由 |
|---|---|---|---|
| SpO₂ | 経皮的動脈血酸素飽和度（peripheral oxygen saturation） | パルスオキシメータが推定する酸素飽和度 | 信号不良、末梢循環、皮膚色素、貧血などの影響を受ける |
| ETCO₂ | 呼気終末二酸化炭素（end-tidal carbon dioxide） | 呼気の最後に測る二酸化炭素 | 肺血流、死腔、換気、回路の影響を受け、動脈血二酸化炭素分圧と同一ではない |
| ABG | 動脈血液ガス分析（arterial blood gas analysis） | 酸塩基、酸素化、換気を評価する採血検査 | 採血条件、吸入酸素濃度、体温、循環と一緒に解釈する |
| MAP | 平均動脈圧（mean arterial pressure） | 一心拍を通した平均的な動脈圧 | 血流量や臓器灌流を直接保証しない |
| CRT | 毛細血管再充満時間（capillary refill time） | 末梢を圧迫後、色が戻るまでの時間 | 室温、照明、皮膚、測定部位、観察者の影響を受ける |
| GCS | グラスゴー・コーマ・スケール（Glasgow Coma Scale） | 開眼・言語・運動反応を記録する尺度 | 合計点だけでは左右差、挿管、鎮静、評価不能を表せない |
| ICP | 頭蓋内圧（intracranial pressure） | 頭蓋内の圧力 | 波形、測定位置、全身状態、脳灌流と統合する必要がある |
| AKI | 急性腎障害（acute kidney injury） | 短期間に腎機能が悪化する病態 | クレアチニン上昇は遅く、尿量低下には閉塞や循環不全など複数原因がある |
| CRRT | 持続的腎代替療法（continuous renal replacement therapy） | 血液から水分・溶質を持続的に除く治療 | 処方量と実施量が異なり、回路・血流・中断・抗凝固の影響を受ける |

詳細は[集中治療用語集](00_Fundamentals/Glossary/CRITICAL_CARE_GLOSSARY.md)を参照する。

## 推奨する順番

1. **基礎：** [ABCDE再評価](00_Fundamentals/ABCDE/README.md)と[臨床推論](00_Fundamentals/Clinical_Reasoning/CLINICAL_REASONING.md)
2. **気道：** [気道評価](01_Airway/Assessment_Emergencies/AIRWAY_ASSESSMENT_EMERGENCIES.md)から、救助要請と代替手段を学ぶ
3. **呼吸：** [呼吸生理](02_Breathing/Respiratory_Physiology/RESPIRATORY_PHYSIOLOGY.md)から酸素化・換気・呼吸仕事量を分ける
4. **循環：** [ショック](03_Circulation/Shock/SHOCK.md)から血圧と組織灌流を分ける
5. **神経：** [神経学的評価](04_Neurology/Assessment/NEUROLOGICAL_ASSESSMENT.md)から左右差と時間変化を記録する
6. **腎臓：** [急性腎障害](05_Renal/AKI/AKI.md)から尿量低下を輸液指示と同一視しない考え方を学ぶ

## 新人看護師の到達目標

- 略語を正式名称と患者の所見へ言い換えられる。
- 急変時に、最初の観察、応援要請、再評価時刻を言える。
- 数値だけでなく、測定条件と変化の方向を申し送れる。
- 介入後に「何が改善すれば成功か」「何が起きれば中止・相談か」を確認できる。

## ベテラン看護師の確認点

- 複数病態、治療による表現型変化、測定誤差を明示しているか。
- 一律の閾値や単一指標で診断・治療を完結させていないか。
- 新人が観察できる所見を、専門的な病態仮説と安全なエスカレーションへ接続できるか。
- 機器、薬剤、施設手順に依存する内容を一般論と混同していないか。
