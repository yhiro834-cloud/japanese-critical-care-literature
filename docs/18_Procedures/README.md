1. [手技安全framework](Safety_Framework/PROCEDURAL_SAFETY_FRAMEWORK.md)で適応、同意、timeout、救済、post-checkを学ぶ。
2. [血管・胸腔・腰椎手技の安全](Common_Procedures/COMMON_PROCEDURE_SAFETY.md)でdevice別riskと手技後観察を学ぶ。

操作技術ではなく、安全な準備、観察、報告、合併症発見、抜去までを扱う。
