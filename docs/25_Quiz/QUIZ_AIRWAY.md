# Quiz: Airway

## Questions

1. 上気道閉塞が完全になるとstridorはどうなることがあるか。
2. awake intubationを検討する4つの観点を挙げよ。
3. 挿管後、聴診良好だがsustained ETCO₂がない。次の基本姿勢は？
4. suction catheterがETTを通らないときに疑うことは？
5. difficult airway記録に残すべき項目を3つ挙げよ。
6. SBTとairway extubation readinessの違いは？

## Answers

1. airflow消失によりstridorも消え、silent airwayとなり得る。
2. difficult ventilation、aspiration risk、apnea intolerance、emergency invasive access difficulty。
3. 食道挿管を積極的に除外し、quick checkとoxygenation/rescueを急ぐ。CXRを待たない。
4. tube obstruction/kinking/malpositionなど。
5. 例：attempt数、device、laryngeal view、成功手技、合併症、mask/SGA ventilation。
6. SBTは自発呼吸耐容性、抜管には上気道・cough・secretions・protection・rescueも必要。
