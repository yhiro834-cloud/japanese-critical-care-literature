# Quiz: Shock / Septic Shock

## Basic

### Q1

Shockの定義として最も適切なのは？

A. MAP <65 mmHg  B. lactate >2 mmol/L  C. 循環が組織需要を満たせず臓器障害が進む症候群  D. vasopressorが必要な状態

**Answer:** C

**Explanation:** 低血圧、lactate、vasopressorは手掛かり・criteriaですがShock全体の定義ではありません。

### Q2

2026 SSCでseptic shockのfirst-line vasopressorとして推奨されるのは？

**Answer:** Norepinephrine。

**Explanation:** 個別の投与量・経路は施設protocolを参照します。

## Intermediate

### Q3

MAP 68 mmHgへ改善したため蘇生完了と判断した。問題点は？

**Answer:** MAPだけでは組織灌流を評価できない。CRT、意識、尿量、lactate trend、呼吸と有害事象を再評価する。

### Q4

PLRでSVが増えた。直ちに大量輸液すべきか？

**Answer:** いいえ。

**Explanation:** Fluid responsiveでも灌流改善の必要性とfluid toleranceがなければ治療利益は保証されません。

## Advanced

### Q5

CLASSICとCLOVERSから「restrictive fluidが標準」と断定できるか？

**Answer:** できない。

**Explanation:** 各試験のrestrictive strategyは比較strategyに対して主要死亡outcomeを有意に改善しませんでした。患者、時相、既投与量、toleranceを踏まえた個別化が必要です。

### Q6

Lactateが上昇し続けるとき、追加輸液以外に何を再評価する？

**Answer:** 低灌流/source control、cardiac/obstructive/hemorrhagic component、β刺激、痙攣、肝clearance、採血条件など。

## Case-based

### Q7

肺炎疑い、MAP 55、CRT 5秒、意識変化。最初の行動を順に述べる。

**Answer:** 患者を直接評価し応援要請、ABCDEと測定確認、monitor/access、感染治療と循環支持を並行、介入前後でperfusionと害を再評価する。
