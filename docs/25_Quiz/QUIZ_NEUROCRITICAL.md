# Quiz: Neurocritical Care

## Questions

1. `GCS 8`より安全な記録例は？
2. 瞳孔不同で最初に同時確認する全身項目を3つ挙げよ。
3. EVD level/zeroを再確認すべき場面は？
4. cEEGの代表的適応を2つ挙げよ。
5. 2026 AIS guidelineが置換した旧版は？
6. neuroprognosticationの3原則は？

## Answers

1. 例：`E2 Vt M5、右上肢は局在、鎮静中`。
2. 例：airway/O₂/CO₂、BP/CPP、glucose、temperature、薬剤。
3. 体位/bed height変更、搬送、波形/排液変化、shift handoff。
4. status後に意識が戻らない、acute brain injuryで意識変化、unexplained coma、疑わしい発作。
5. 2018 guidelineと2019 update。
6. delay、deconfound、multimodal（＋不確実性の説明）。
