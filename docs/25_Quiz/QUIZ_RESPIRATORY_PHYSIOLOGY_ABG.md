# Quiz: Respiratory Physiology / ABG

## Basic

### Q1

SpO₂ 99%ならalveolar ventilationは十分である。正しいか？

**Answer:** 誤り。Supplemental oxygen下ではhypoventilationでもSpO₂が保たれ、PaCO₂が上昇し得る。

### Q2

CaO₂に最も大きく寄与するのは？

**Answer:** Hb-bound oxygen（HbとSaO₂）。溶存oxygenの寄与は通常小さい。

## Intermediate

### Q3

`pH 7.28 / PaCO₂ 25 / HCO₃ 12`。Primary processとexpected PaCO₂は？

**Answer:** Metabolic acidosis。Winter式で約26±2 mmHgで、compensationは概ね期待範囲。

### Q4

`pH 7.40 / PaCO₂ 20 / HCO₃ 12`を「正常」と判断してよいか？

**Answer:** いいえ。低PaCO₂と低HCO₃があり、mixed/compensated processを評価する。

## Advanced

### Q5

Albumin 2.0 g/dL、AG 12。Corrected AGの概算は？

**Answer:** `12 + 2.5 × (4−2) = 17`。隠れたunmeasured anionを疑う手掛かりになる。

### Q6

Peripheral VBGのPvCO₂をPaCO₂の正確な代用にできるか？

**Answer:** 一律にはできない。Agreementのlimitsが広く、目的・状況・local validationが必要。

## Case-based

### Q7

Oxygen therapy中、RRが34から16へ低下したが傾眠が進行。SpO₂ 94%。何を懸念する？

**Answer:** 改善ではなくrespiratory muscle fatigueとhypercapnic ventilatory failure。患者評価、airway、ETCO₂/ABG、ventilatory supportを緊急検討する。
