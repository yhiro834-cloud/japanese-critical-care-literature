# Quiz: Renal

## Questions

1. KDIGO AKI定義の3つの入口は？
2. Fluid decisionでcongestionを見る理由は？
3. Hyperkalemia治療の4機能を挙げよ。
4. Hyponatremiaで補正前に決める安全項目は？
5. CRRTのCVVH/CVVHD/CVVHDFの主機序は？
6. Access pressure alarmで最初に確認する順序は？

## Answers

1. 48h SCr +0.3、7日で≥1.5倍、尿量<0.5 mL/kg/h 6h。
2. fluid responsiveでも肺/RV/静脈うっ血を悪化させbenefitがないことがある。
3. 心筋保護、細胞内shift、体外removal、原因治療/再検。
4. 症状、acute/chronic、高risk、補正target/ceiling、再検時刻、overcorrection rescue。
5. convection、diffusion、両者。
6. patient→access/catheter→circuit→machine。
