# Quiz: Respiratory Support

## Questions

1. HFNC中のSpO₂が改善した。RRと努力呼吸が悪化している場合の最適な解釈は？
2. Ppeakが上昇したがPplatは不変。まず疑うmechanicsは？
3. driving pressureの式は？
4. ARDSでVT設定に用いる体重は？
5. SBTとextubation readinessの違いを1つ述べよ。
6. NIV failureを示すred flagを3つ挙げよ。

## Answers

1. support failureの可能性があり、原因再評価とescalationを急ぐ。SpO₂単独で成功としない。
2. airway/tube/secretions/bronchospasm等のresistance増大（測定条件も確認）。
3. `Pplat − total PEEP`。
4. predicted body weight（PBW）。実体重ではない。
5. SBTは自発呼吸耐容性、抜管にはairway/cough/secretions等も必要。
6. 例：意識低下、pH低下、WOB増大、shock、分泌排出不能、refractory hypoxemia。
