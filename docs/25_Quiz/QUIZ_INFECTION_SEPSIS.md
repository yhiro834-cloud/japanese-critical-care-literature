# Quiz: Infection / Sepsis

## Questions

1. Infection assessmentの5要素は？
2. Blood culture qualityを左右する項目を3つ挙げよ。
3. Empiric antibiotic設計に必要な項目を4つ挙げよ。
4. Source controlの例を3つ挙げよ。
5. Antibiotic timeoutの5つの問いは？
6. Culture-negative feverで再評価するmimicを3つ挙げよ。

## Answers

1. host、source/syndrome、pathogen/MDR risk、organ dysfunction、mimic。
2. volume、set数、site、antisepsis、時刻/抗菌薬前、label。
3. source/pathogen、severity、MDR/local antibiogram、allergy、organ function、PK/PD/support。
4. drainage、debridement、device removal、obstruction relief、surgery。
5. probability/source、organism/quality、response/control、narrow/stop/dose/route、duration/end date。
6. 例：PE、drug fever、hemorrhage、pancreatitis、withdrawal、endocrine、transfusion reaction。
