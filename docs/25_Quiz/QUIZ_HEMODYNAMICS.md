# Quiz: Hemodynamics

## Questions

1. `CO`と`DO₂`の基本式は？
2. Fluid decisionの3要素は？
3. PPV/SVVが信頼しにくい条件を2つ挙げよ。
4. Arterial waveformがdampedなら最初に何を確認するか。
5. POCUSのnegative studyに必要な前提は？
6. Vasoactive infusion突然不応時のsystem checkを3つ挙げよ。

## Answers

1. `CO = HR × SV`、`DO₂ = CO × CaO₂`。
2. need、responsiveness、tolerance。
3. 例：自発呼吸、不整脈、低VT、open chest、RV dysfunction。
4. level/zero、tubing、air/clot、pressure bag、catheter、waveform quality。
5. 問いに適した十分なqualityとview。poor windowはnegativeではない。
6. 例：薬剤/濃度、残量、pump、clamp、接続、line infiltration/dead space。
