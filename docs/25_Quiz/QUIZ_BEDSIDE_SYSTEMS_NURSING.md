# Bedside Systems / Nursing Quiz

## Q1

A-line急低下時の最初の行動は？

A. vasopressor即増量のみ  B. patient/pulse確認と測定系評価  C. alarm off  D. 翌朝校正

**Answer: B.** true deteriorationとartifactを並行評価する。  
**Knowledge:** [Monitoring](../19_Monitoring/Core_Monitoring/MONITORING_WAVEFORMS_ARTIFACT.md)

## Q2

device alarmで適切なのは？

A. reset反復  B. independent patient support後に両端trace  C. unknown lineへflush  D. batteryなしで搬送

**Answer: B.** patient dependenceを先に支える。  
**Knowledge:** [Device Lifecycle](../20_Devices/Lifecycle/DEVICE_LIFECYCLE_BACKUP.md)

## Q3

良いhandoffに含むのは？

A. diagnosisのみ  B. trend・response・pending・contingency・goals  C. stableの一語  D. monitor値のみ

**Answer: B.** 次の悪化を予測できる情報を渡す。  
**Knowledge:** [Systematic Nursing](../22_Nursing/Systematic_Care/SYSTEMATIC_ICU_NURSING_CARE.md)
