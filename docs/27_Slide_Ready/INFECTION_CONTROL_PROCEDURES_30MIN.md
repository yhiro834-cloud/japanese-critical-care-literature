# Infection Control / Procedures — 30-minute Slide Ready

## Learning Objectives

1. standard/transmission precautionsをrisk-basedに適用する。
2. device infectionをlifecycleで予防する。
3. procedureをtimeout–monitor–post-checkで安全化する。
