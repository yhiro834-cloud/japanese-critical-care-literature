# Endocrine / Metabolic — 30-minute Slide Ready

## Learning Objectives

1. DKA/HHSをglucose以外のphysiologyで追跡する。
2. ICU glucose protocolの高risk transitionを説明する。
3. adrenal/thyroid/temperature emergencyを遅滞なく認識する。
