# Critical Care Fundamentals：中堅ICU看護師向け30分

## Knowledge Base coverage

利用可能：oxygen pathway、pressure/flow/perfusion、problem representation、diagnostic timeout、systematic assessment、POCUSの位置づけ、closed loop、incident learning、症例、Quiz。

**Knowledge Baseに情報不足:** 施設固有rapid response基準、handoff様式、POCUS credentialing、incident reporting手順。

## Learning objectives

1. oxygenationとoxygen delivery、pressureとperfusionを区別できる。
2. 急変時にrescue/diagnose/verifyを並行できる。
3. daily goalsとdiagnostic timeoutを使える。
4. closed-loop communicationを実演できる。

## Slide sequence

1. 0–4分：数字ではなくoxygen pathwayを見る
2. 4–8分：pressure、flow、regional perfusion
3. 8–13分：problem representationとparallel lanes
4. 13–17分：diagnostic timeout
5. 17–21分：three-pass ICU assessmentとdaily goals
6. 21–25分：closed loop、brief/huddle/debrief
7. 25–29分：conflicting signals症例
8. 29–30分：Quizとtake-home
