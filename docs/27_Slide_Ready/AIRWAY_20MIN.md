# Airway — 20-minute Slide Ready

## Learning Objectives

1. impending airway obstructionをSpO₂低下前に認識する。
2. RSIをpreparation–attempt–confirmation–post-careで説明する。
3. tube/tracheostomy急変を構造化して初期対応する。

## Suggested Slide Structure

1. Airwayの問い：open / maintainable / rescuable
2. Look–listen–feelと悪化予測
3. Anatomical vs physiological difficulty
4. Plan A–Dとattempt limitation
5. RSI checklistとteam roles
6. Sustained waveform CO₂
7. Post-intubation bundle
8. DOPES型troubleshooting（患者を先に見る）
9. ETT/cuff/suction/VAP care
10. Extubation is elective
11. 症例
12. Take-home messages
