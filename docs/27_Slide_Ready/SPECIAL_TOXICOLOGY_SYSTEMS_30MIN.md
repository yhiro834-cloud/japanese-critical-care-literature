# Special Populations / Toxicology / Systems：中堅ICU看護師向け30分

## Learning objectives

1. 成人一般からの外挿を止めるcheckpointを説明できる。
2. unknown poisoningをsupportive careとserial assessmentで整理できる。
3. shared decision、transport、incident reviewをsystemとして説明できる。

## Slide sequence

1. 0–3分：同じABCDE、異なるbaseline
2. 3–9分：小児・妊産婦・complex adults
3. 9–15分：toxidromeは仮説、支持療法が土台
4. 15–19分：environmental emergencies
5. 19–24分：patient valuesからtime-limited trialへ
6. 24–28分：human factors、搬送、災害、QI
7. 28–30分：症例とtake-home messages

## Optional Figure Extensions

- 「common ABCDE → population-specific modifiers → specialist/local protocol」のflow

## Speaker notes

数値やdrug listの暗記ではなく、成人知識の自動適用・原因物質当て・個人責任化という3つのpremature closureを対比する。
