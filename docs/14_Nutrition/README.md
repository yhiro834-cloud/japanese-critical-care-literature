# 14 Nutrition

## 推奨学習順序

1. [重症患者の栄養療法](Critical_Care_Nutrition/CRITICAL_CARE_NUTRITION.md)でroute、実投与量、耐容性を学ぶ。
2. [Refeeding syndrome](Refeeding/REFEEDING_SYNDROME.md)で開始前risk、電解質、thiamine、段階的増量を学ぶ。

栄養は薬剤・血糖・呼吸・腎代替療法・離床と相互作用するため、24時間の実投与と患者反応を共通timelineで扱う。
