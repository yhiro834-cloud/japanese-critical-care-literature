# Teaching Recomposition Guide

## 1. Coverage gate

最初に[Topic Map](../TOPIC_MAP.md)、Knowledge本体、Case、Quiz、Guideline/Referenceを確認する。本体にない内容は外部知識で埋めず、`Knowledge Baseに情報不足`として執筆候補へ戻す。

## 2. Duration matrix

| 時間 | 構成 | 到達点 |
|---|---|---|
| 5分 | 1危険徴候 + 1行動 + 1再評価 | bedsideで見逃さず報告できる |
| 10分 | 5分版 + 最小生理 + mini case | なぜその行動か説明できる |
| 20分 | assessment/鑑別/介入 + case + quiz | 仮説を比較し再評価できる |
| 30分 | evidence/限界/team/nursing + case discussion | 優先順位と実装を議論できる |

## 3. Audience transform

| 対象 | 残す | 深める | 評価方法 |
|---|---|---|---|
| 新人 | normal/abnormal、red flag、報告 | 手順と観察 | teach-back / 基礎問 |
| 中堅 | pattern、differential、trend | reasoning、troubleshooting | 症例分岐 / 中級問 |
| リーダー | uncertainty、resource、safety | team allocation、Evidence限界 | simulation/debrief / 上級問 |

## 4. Build record

各教材に対象、時間、prerequisite、objectives、source links、excluded details、case/quiz、speaker notes、slide references、review dateを残す。医学的主張を変更する場合は教材ではなくSSOTを先に更新する。

## 5. Quality gate

- objectivesと評価問題が一致する
- 高リスク行動にlocal protocol/specialist checkがある
- physiology→assessment→reasoning→treatment→nursing→reassessmentが途切れない
- 図が未作成なら未作成と明示する
- audience/timeを変えてもEvidenceの意味を変えない
