# Shock: Multi-duration / Multi-audience Example

Source of truth: [Shock](../03_Circulation/Shock/SHOCK.md)、[Septic Shock](../03_Circulation/Shock/SEPTIC_SHOCK.md)、[case](../23_Clinical_Cases/CASE_SUDDEN_HYPOTENSION_SEPTIC_SHOCK.md)、[quiz](../25_Quiz/QUIZ_SHOCK_SEPTIC_SHOCK.md)。

| 対象 | 5分 | 10分 | 20分 | 30分 |
|---|---|---|---|---|
| 新人 | shock red flagsと即時報告 | MAP以外のperfusion | ABCDE、観察、症例 | team内の観察・安全・再評価 |
| 中堅 | phenotypeを一言で共有 | preload/flow/tone | differentialとfluid/vasoactive response | Evidence限界を含むcase discussion |
| リーダー | rolesと5分後再評価 | parallel tasksとescalation | resource allocation、source control | simulation、handoff、debrief、QI |

## 20-minute middle-level run sheet

1. 0–3分：problem representationとred flags
2. 3–7分：pressure ≠ flow ≠ perfusion
3. 7–11分：shock phenotypeとmixed shock
4. 11–16分：突然低血圧症例、intervention-response
5. 16–19分：fluid/vasopressorのbenefit-harm再評価
6. 19–20分：quizとtake-home

## What is intentionally excluded

施設固有のdrug concentration、pump library、massive transfusion activation、POCUS credentialingはKnowledge Baseだけでは確定できないため、local protocolへ接続する。
